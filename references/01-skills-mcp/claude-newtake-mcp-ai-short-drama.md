# 클로드에 뉴테이크 MCP 연결해서 AI 숏드라마 만드는 법
- 원문: https://lazyowen.com/guides/claude-newtake-mcp-ai-short-drama
- 도구·주제: Claude / Claude Code + Newtake MCP · AI 숏드라마(이미지→영상) 제작 (2026-11-04 공개, STEP 4개, 약 18분)
- 한 줄 요약: Newtake 원격 MCP를 Claude에 연결해 캐릭터 시트·배경 → 5단계 장면 설계 → 태그한 에셋으로 15초 9:16 영상을 생성한다.

## 언제 쓰나
- 캐릭터 일관성을 유지한 15초 안팎 세로 숏드라마를 만들고 싶을 때
- 캐릭터 시트, 장면 설계, 영상 생성을 Claude 대화창 하나에서 이어서 처리하고 싶을 때
- 뉴테이크는 아이디어·대본·레퍼런스 이미지로 이미지·영상을 만드는 AI 비주얼 캔버스. 클로드가 직접 그리는 게 아니라 내 뉴테이크 계정에 생성을 요청하고, 결과는 계정에 쌓여 캔버스에서 이어 편집 가능

## 준비물 / 필요 도구
- Newtake(뉴테이크) 계정 — https://www.newtake.ai/?sourceId=NT920395 (오픈소스 아님, 웹 서비스)
- 공식 원격 MCP 주소: `https://mcp.newtake.ai/mcp` (뉴테이크 팀 운영)
- 공식 GitHub: https://github.com/newtake-ai/marketplace
- Claude 커넥터 설정: https://claude.ai/customize/connectors
- 커스텀 커넥터 도움말: https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp
- Claude Code 설치: https://code.claude.com/docs/en/setup
- 환경: claude.ai 웹 / 데스크톱 앱 또는 터미널의 Claude Code
- 영상 모델: Seedance 2.5 (뉴테이크에서 선택. 내 계정에서 쓸 수 있는 모델은 "쓸 수 있는 영상 모델 알려줘"라고 물으면 목록 확인)
- 비용: 커스텀 커넥터는 무료 요금제도 1개까지 가능. 이미지·영상 생성은 내 뉴테이크 계정에서 실행(구체 요금 미기재)

## 단계별 방법
**Quick Start**: 뉴테이크 가입 → 클로드 커넥터 화면에서 이름 `Newtake`, 주소 `https://mcp.newtake.ai/mcp`로 커스텀 커넥터 추가 → 로그인 후 대화창에서 이미지·영상 생성

**프롬프트 뼈대 0 (Claude Code용 연결 대행)**: 터미널에서 `claude` 실행 후 첫 메시지로 사용. 역할은 "뉴테이크 MCP 연결·상태 확인 담당", 초보자·계정은 이미 있음. 채울 곳: [내 목표 한 줄 — 예: 15초 로맨스 판타지 코미디]. 작업: `claude --version` → `claude mcp list`로 newtake 유무 확인(없을 때만 add) → 재확인 → Needs authentication이면 `/exit` → `claude` 재실행 → `/mcp`로 newtake 로그인 안내 → 이후 캐릭터 시트→장면 설계→영상 생성 순서를 초보자 눈높이로 설명. 제약: sudo·전역 설치·설정 직접 수정 전 질문, 토큰·비밀키 미출력, 기존 연결 덮어쓰기 금지. 검증: `claude mcp list`에 `newtake: https://mcp.newtake.ai/mcp (HTTP)` 줄이 있고 로그인 후 Needs authentication이 사라져야 성공, 하나라도 실패하면 완료 보고 금지

**STEP 1. MCP 연결 (3분)**
- 방법 A (웹/앱):
  1. 뉴테이크 가입
  2. https://claude.ai/customize/connectors 열기
  3. `+ Add` → `Add custom connector`
  4. 이름 `Newtake`, 주소 `https://mcp.newtake.ai/mcp` → `Continue`
  5. 감지된 인증 설정은 그대로 `Continue` (OAuth client는 추천값 `Use Claude's published identity` 유지)
  6. `Add` → 뉴테이크 로그인 창에서 가입 계정으로 로그인
  - 이후 대화창 왼쪽 아래 `+` → `Connectors`에서 대화마다 켜고 끌 수 있음
  - 클로드가 뉴테이크 도구 사용 허가를 물으면 무엇을 만들려는지 읽고 허용
- 방법 B (Claude Code):
```bash
claude --version                # 없으면 https://code.claude.com/docs/en/setup 따라 설치
claude mcp list                 # newtake가 이미 보이면 add 건너뜀
claude mcp add --transport http --scope user newtake https://mcp.newtake.ai/mcp
claude mcp list
```
  - add 성공 메시지: `Added HTTP MCP server newtake with URL: https://mcp.newtake.ai/mcp to user config`
  - list에서 `newtake: https://mcp.newtake.ai/mcp (HTTP) - ! Needs authentication`이면 등록됨, 로그인 전
  - 실행 중이면 `/exit` → `claude` 재실행 → `/mcp` → newtake 선택 → 브라우저 로그인 → 다시 `claude mcp list`에서 표시가 사라지면 성공

**STEP 2. 캐릭터 시트·배경 이미지 (5분)**
- 캐릭터 시트 = 한 인물의 전신 정면·측면 + 얼굴 클로즈업을 한 장에 모은 이미지(영상 생성 때 인물 참조용)
- 예시 영상은 주인공(카와이 지하돌 스타일 여성), 북부대공, 왕자 3명 + 궁전 연회장 배경
- 프롬프트 뼈대: 뉴테이크로 캐릭터 시트 [N]장 + 배경 1장을 각각 생성. 모든 인물은 성인. 시트는 한 장 네 컷(위 두 컷 전신 정면·측면, 아래 두 컷 얼굴 클로즈업). 인물마다 [머리색·머리 모양, 옷, 소품, 클로즈업 포즈]를 한 줄씩 상세 기재. 배경은 [장소 묘사]를 인물 없이. 실사 드라마처럼 밝고 부드러운 조명, 이미지에 글자·로고 금지, 인물/배경은 영상에서 각각 참조하도록 따로 생성
- 컷마다 머리색·옷 색이 다르면 다른 부분만 짚어 재요청. 실존 인물 사진 레퍼런스는 본인 동의 사진만

**STEP 3. 5단계 스토리를 장면으로 설계 (5분)**
- 긴 영상 프롬프트를 직접 쓸 필요 없이 이야기 순서·대사·지킬 조건만 적으면 클로드가 설계를 채움
- 프롬프트 뼈대: 앞서 만든 인물·배경으로 [장르] 숏드라마. 번호 1~5로 [사건 + 인물별 대사]를 적음(예시: 약혼 파기 선언 → 손가락 하트 → 북부대공 등장 → "체키는 줄 서서" → "맨 뒤가 어디지?"). 웃음은 과장 효과 대신 진지한 표정과 엉뚱한 대사의 차이로, 화면 자막·글자 금지. 요청 출력: 장면별 동작·표정, 카메라 구도, 대사, 연속성
- 예시 완성 설계(구도): 약혼 파기=주인공 어깨 너머 왕자 바스트 샷 / 손가락 하트=주인공 정면 미디엄 샷 / 북부대공 등장=문 앞 풀 샷→미디엄 샷 / 줄 서세요=북부대공 장갑 너머 주인공 / 맨 뒤가 어디지=북부대공 얼굴 클로즈업. (바스트=가슴 위, 미디엄=허리 위, 풀=머리~발끝)
- 영상의 시간 흐름 예: 0초 왕자 → 2초 하트 → 5초 문 앞 대공 → 7초 장갑 너머 주인공 → 11초부터 대공 클로즈업
- 마음에 안 들면 바꿀 장면 번호와 원하는 표정만 지정해 재요청

**STEP 4. 이미지 에셋 태그 후 영상 생성 (5분)**
- 태그 = 이미지마다 '이건 배경, 이건 주인공'처럼 역할 이름표를 붙여 얼굴·옷이 섞이지 않게 함
- 프롬프트 뼈대: 만든 에셋을 태그해 영상 생성. [배경, 인물 A/B/C] 각각의 역할 지정, 모든 장면에서 얼굴·착장 유지. 모델·길이·비율을 한 줄로 `Seedance 2.5 / 15초 / 9:16`. 5단계 이야기와 5개 대사가 이어지게 장면 수·호흡을 15초에 맞춰 정리
- 결과는 내 뉴테이크 계정에 저장, 캔버스에서 재오픈. 마음에 안 들면 같은 프롬프트로 재생성하거나 어긋난 장면만 짚어 수정 요청

**완성 영상 확인 항목**
- 인물 얼굴·머리·옷 색이 처음부터 끝까지 같은가
- 5단계가 순서대로 이어지고 대사가 입 모양과 맞는가
- 캐릭터 시트 특징(예: 흉터, 검은 장갑)이 장면마다 남았는가
- 자막·글자·로고가 섞이지 않았는가
- 길이 15초 안팎, 세로 9:16인가
- 다른 이야기로 만들 땐 STEP 2의 인물 설명과 STEP 3의 5단계·대사만 교체

## 핵심 팁 · 주의사항
- ❌ "귀여운 아이돌 캐릭터랑 무서운 공작 만들어줘" → ✅ 머리색·머리 모양·옷 색·소품을 인물마다 한 줄씩
- ❌ "웃긴 로판 장면 하나" → ✅ 순서 번호, 인물별 대사, 웃음 방식까지 지정
- ❌ "아까 이미지로 영상 만들어줘" → ✅ 이미지마다 역할 + 모델·길이·비율 한 줄 지정
- 연결 후 반드시 뉴테이크 로그인 완료(로그인 전에는 `Needs authentication`)
- 이미 newtake가 등록돼 있으면 `claude mcp add` 재실행 금지
- 연결하면 클로드가 내 뉴테이크 계정에서 프로젝트를 만들고 생성을 실행함 → 도구 사용 허가 시 내용 확인
- 실존 인물 레퍼런스는 본인 동의 사진만

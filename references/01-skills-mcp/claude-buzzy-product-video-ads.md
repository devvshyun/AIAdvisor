# 클로드·버지로 시네마틱 광고 5개
- 도구·주제: Claude Code + Buzzy(버지) MCP · 제품 사진 → 영상 광고 (2026-10-25 갱신, STEP 5개)
- 한 줄 요약: Buzzy MCP를 Claude Code에 연결해 제품 사진 한 장으로 15초 광고를 만들고, 같은 사진으로 조명·각도가 다른 5개 버전을 뽑아 폴더에 모은다.

## 언제 쓰나
- 제품 사진 하나로 여러 컨셉(조명·각도·시작 문구)의 짧은 광고 영상을 만들고 싶을 때
- 버지는 사진+설명으로 이미지·영상을 만드는 서비스(운영사 Buzzy AI). 클로드가 제작을 지시하고 버지가 생성한다

## 준비물 / 필요 도구
- 맥 또는 윈도우의 Claude Code(앤트로픽), 인터넷, 버지 계정, 제품 사진
- Buzzy: https://buzzy.now · MCP 안내 https://www.buzzy.now/mcp · 요금 https://www.buzzy.now/pricing · 약관 https://www.buzzy.now/terms-and-conditions
- Claude Code: 빠른 시작 https://code.claude.com/docs/en/quickstart · MCP 관리 https://code.claude.com/docs/en/mcp · 터미널 입문 https://code.claude.com/docs/en/terminal-guide · 백그라운드 작업 https://code.claude.com/docs/en/interactive-mode#background-bash-commands
- 비용: 버지는 가입 후 일부 기능만 제한적 체험, 추가 생성·유료 기능은 결제. 영상 생성은 크레딧 소모(길이·모델별 상이). Claude Code 이용료는 별도. 유료 요금제 선택 시 금액과 자동 갱신 조건 확인
- 용어: MCP = 클로드가 외부 도구를 부르는 연결 규격 / 크레딧 = 버지 영상 생성 이용량 단위

## 단계별 방법
**Quick Start** (Claude Code가 이미 설치돼 있을 때)
```bash
claude mcp add --transport http buzzy https://mcp.buzzy.now/mcp
```
- 성공하면 buzzy 등록 안내가 뜬다. 계정 인증은 STEP 2에서 한다.

**프롬프트 뼈대 ① 연결 확인 + 첫 광고 준비** (Claude Code 대화창에 붙여넣기)
- 목적: 설치·MCP 등록 상태를 확인하고 첫 광고를 준비. 역할은 "버지 연결 확인·첫 광고 준비 담당자", 초보자라는 맥락
- 채울 곳: [내 목표 — 예: 따뜻한 조명+한국어 내레이션 15초 시네마틱 광고]
- 작업 순서: OS·작업 폴더 확인 → `claude --version`, `claude mcp get buzzy` 확인 → 버지가 없을 때만 설정 변경을 설명·승인받고 add 실행 → 다시 get으로 확인, 인증 필요하면 `/mcp` 로그인 안내 → 사진 첨부·제작 방식·예상 크레딧 확인까지 안내
- 제약: sudo·전역 설치·설정 파일 수정 전 질문, 비밀키·로그인 정보 출력 금지, 기존 파일 덮어쓰기 금지, 생성·결제·크레딧 구매는 승인 없이 금지
- 출력/검증: 실행 명령, 버전, 바뀐 파일, 등록·인증 상태, 남은 오류. 서버 주소가 https://mcp.buzzy.now/mcp 인지 확인, 하나라도 실패하면 완료 보고 금지. (이 프롬프트는 유료 생성을 시작하지 않음)

**STEP 1. 클로드 코드에 버지 연결하기**
1. 터미널 열기: 맥은 Cmd+Space → Terminal, 윈도우는 시작 메뉴 → PowerShell
2. 설치 확인
```bash
claude --version
```
   - 버전 숫자와 (Claude Code)가 나오면 설치된 것(예: `2.1.302 (Claude Code)`)
3. 없으면 설치 (한 가지만 실행, 끝나면 터미널을 새로 열어 위 확인 명령 재실행)
```bash
curl -fsSL https://claude.ai/install.sh | bash        # macOS
```
```powershell
irm https://claude.ai/install.ps1 | iex               # Windows PowerShell
```
4. 버지 가입: 홈페이지(https://buzzy.now) 오른쪽 위 'English' 옆 'Start for free'
5. MCP 등록(Quick Start 명령). 등록은 현재 작업 폴더 기준이므로 다음에도 같은 폴더에서 claude를 실행. "이미 있음" 오류가 나면 다시 add하지 말고 확인
6. 등록 확인
```bash
claude mcp get buzzy
```
   - 주소가 https://mcp.buzzy.now/mcp 인지 보고, 인증 필요라고 나오면 다음 단계에서 로그인

**STEP 2. 사진 한 장으로 첫 15초 광고**
1. `claude` 실행(첫 실행은 브라우저에서 클로드 계정 로그인)
2. 대화창에 `/mcp` 입력 → buzzy 선택 → 브라우저에서 버지 로그인 → 같은 목록에서 연결 상태 확인
   - 인증 오류: `/mcp`에서 재인증. 링크가 안 열리면 표시된 링크를 브라우저에 붙여넣기. 비밀번호·인증 코드는 대화창에 입력 금지
3. 제품 사진을 입력창에 끌어다 놓고 요청 전송

**프롬프트 뼈대 ② 첫 광고**
- 목적: 첨부 사진으로 15초 시네마틱 광고 생성. 채울 곳: 조명 분위기(따뜻한 조명·고급스러움), 내레이션 언어(한국어)
- 제약: 제품 색·모양·로고는 사진과 동일, 효능 날조 금지, 설명을 자세한 제작 프롬프트로 변환해 맞는 버지 제작 방식을 선택
- 승인 절차: 생성 전에 모델·소리 포함 여부·예상 크레딧을 보여주고 승인받기. 비용 확인이 불가하면 생성하지 말고 확인처 안내
- 출력: 영상 링크와 실제 길이

완성본은 직접 재생해 15초 길이·내레이션 확인. 소리가 없으면 음성 포함해 다시 요청.

**STEP 3. 한 문장으로 수정하기**
- 유지할 요소와 바꿀 요소를 함께 적는다. 재생성 전 크레딧 확인
- 프롬프트 뼈대 ③: 방금 광고를 [더 어둡고 대비 강하게], 내레이션 빼고 [더 강한 배경음악]으로, 제품·15초는 유지. 재생성 크레딧을 알리고 승인 후 실행, 수정본 링크와 변경점 요약
- 제품이 원본과 다를 때: 제품이 크게 나온 장면에서 멈춤 → 원본 사진과 색·모양·글자 대조해 바뀐 부분 하나 고르기 → "조명은 유지하고 제품 색은 첨부 사진과 같게" 식으로 요청 → 같은 장면 재확인. 계속 다르면 해당 장면+사진을 다시 주고 그 부분만 수정. 없는 효능 문장이 들어갔으면 삭제
- 음악을 광고에 쓸 때는 이용 조건 확인

**STEP 4. 같은 사진으로 광고 5개**
- 제품·15초는 동일, 버전별 차이만 정의. 한 번에 요청해도 비용은 각각 적용되므로 전체 예상 크레딧 먼저 확인

| # | 조명 | 카메라 | 시작/마무리 |
|---|---|---|---|
| 1 | 따뜻한 조명 | 정면에서 천천히 접근 | 제품 이름으로 시작 |
| 2 | 차가운 조명 | 옆면 이동 | 사용 상황으로 시작 |
| 3 | 어두운 배경 | 위에서 내려다봄 | 눈에 보이는 특징으로 시작 |
| 4 | 부드러운 조명 | 표면 가까이 촬영 | 질감으로 시작 |
| 5 | 윤곽 조명 | 제품 주변을 도는 시점 | 제품 이름으로 마무리 |

- 프롬프트 뼈대 ④: 같은 사진으로 15초 광고 5개, 위 표 내용을 번호로 나열. 기획과 한국어 내레이션 문장을 먼저 보여주기, 사진·제공 정보에 없는 효능·할인·후기 금지, 제작 방식과 5개 전체 예상 크레딧 승인 후 버지가 허용하는 동시 작업 범위 내에서 생성, 완료 시 번호별 링크+콘셉트 한 줄 정리
- 검수: 링크 5개인지, 제품 모습 유지·기획 차이 반영 여부. 빠진 버전은 진행 상태부터 확인하고 중복 생성 금지

**STEP 5. 기다리는 작업과 완성본 모으기**
- 밤에 맡기기 전 범위 설정: 개인 파일 없는 광고 전용 폴더/별도 컴퓨터 계정, 다운로드 명령·저장 위치 먼저 확인, 컴퓨터는 인터넷 연결·잠자기 끄기
- 백그라운드 작업은 세션을 끝내면 함께 종료(예약 실행과 다름) → 대화창을 닫지 말 것
- 프롬프트 뼈대 ⑤: 앞서 승인한 5개의 진행 상태 확인, 이미 시작한 건 재생성 금지, 상태 확인·다운로드는 백그라운드, 완성본은 작업 폴더의 `pubs-buzzy`에 저장. 다운로드 명령·저장 위치 선승인, 버지가 반환한 링크만 사용, 덮어쓰기 금지, 새 생성·유료 재시도·추가 결제·권한 변경 필요 시 중단 보고, 모든 권한 확인을 끄는 옵션 금지. 마지막에 번호·콘셉트·완료 여부·저장 경로 정리
- 검수: `pubs-buzzy`에서 직접 재생, 5개 여부·길이·소리 확인, 실패/대기 버전은 완료 목록과 분리
- 중단: Esc (버지에 이미 보낸 생성 요청은 별도 작업이니 상태부터 확인)
- 되돌리기(등록했던 폴더에서):
```bash
claude mcp remove buzzy
```
  연결만 해제됨. 유료 구독은 버지 계정에서 별도 취소

## 핵심 팁 · 주의사항
- ❌ 클로드 웹 채팅에 설치 명령 붙여넣기 → ✅ 컴퓨터 터미널에서 실행
- ❌ 사진 없이 "고급 광고 만들어줘" → ✅ 사진+길이·조명·내레이션 지정
- ❌ "별로예요 다시" → ✅ "제품은 그대로, 더 어둡게" 식으로 유지/변경 분리
- ❌ "똑같은 광고 다섯 번" → ✅ 시작 문구·조명·각도를 다르게
- ❌ "추가 결제도 알아서 끝까지" → ✅ 이미 승인한 건만 확인, 새 생성·결제는 멈춤
- 업로드 권한 있는 사진만, 고객 얼굴·주소·미공개 자료 제외. 사진·음악 사용권 확보(버지 약관 적용)
- 효능·할인·후기는 실제 정보일 때만. sudo/전역 설치/설정 파일 수정은 먼저 승인
- 환경 차이: 이미 등록했다면 같은 명령을 재실행하지 말고 STEP 2로

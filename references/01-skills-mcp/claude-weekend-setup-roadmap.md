# 이틀 만에 90%의 사람보다 클로드를 잘 쓰게 되는 로드맵
- 원문: https://lazyowen.com/guides/claude-weekend-setup-roadmap
- 도구·주제: Claude (웹/데스크톱) · 메모리·프로젝트·커넥터(MCP)·스킬 세팅 (스킬·MCP, 공부·리서치, 17분, STEP 5개, 2026-10-28 공개)
- 한 줄 요약: 토요일에 About Me·세컨드 브레인·프로젝트, 일요일에 MCP 앱 연결·스킬을 세팅해, 클로드가 나를 아는 상태로 일하게 만드는 2일 로드맵.

## 언제 쓰나
- 클로드 답이 뻔하게 나오고, 매 대화를 처음부터 시작하는 느낌일 때. 클로드를 개인 비서/업무 도구로 세팅하고 싶을 때.
- 새 프로그램 설치가 아니라 클로드에 이미 있는 메모리·프로젝트·커넥터·스킬을 순서대로 세팅하는 것.

## 준비물 / 필요 도구
- Claude 웹 https://claude.ai · 데스크톱 앱(맥/윈도우) https://claude.com/download (로컬 폴더 읽는 확장은 데스크톱에서만)
- 커넥터: https://claude.ai/customize/connectors · 스킬: https://claude.ai/customize/skills
- 예시 스킬 공식 GitHub: https://github.com/anthropics/skills
- 세컨드 브레인 공간 하나: 노션 / 옵시디언 / 구글 드라이브 (이번 주말에 도구를 갈아타지 말고 지금 쓰는 것)
- 비용: 무료 플랜도 메모리·커넥터·스킬 가능, 프로젝트 5개까지. 지난 대화 검색과 대용량 프로젝트 자료는 Pro 이상.
- 공식 안내: 프로젝트 https://support.claude.com/en/articles/9517075-what-are-projects · 메모리 https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context · 커넥터 https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities · 로컬 MCP https://support.claude.com/en/articles/10949351-getting-started-with-local-mcp-servers-on-claude-desktop · 스킬 https://support.claude.com/en/articles/12512180-use-skills-in-claude · 스킬 만들기 https://support.claude.com/en/articles/12512198-how-to-create-custom-skills

## 일정 (캘린더에 다섯 칸 미리 막기)
| 시간 | 할 일 | 남는 것 |
|---|---|---|
| 토 오전 2h | 질문 50개 인터뷰 | About Me 문서 |
| 토 오후 3h | 세컨드 브레인 세팅 | 프로젝트·할 일·문서 공간 |
| 토 저녁 2h | 업무를 프로젝트로 이전 | 영역별 클로드 프로젝트 |
| 일 오전 2h | MCP로 앱 연결 | 매일 쓰는 앱 3개 연결 |
| 일 오후 3h | 스킬 설치·결과물 제작 | 내 스킬 1개 + 이번 주 결과물 |

결과물은 대화창에만 두지 말고 그때그때 세컨드 브레인에 저장.

## 단계별 방법
### Quick Start
- 웹에서 claude.ai 로그인 → 새 대화 입력창이 보이면 성공. 폴더 연결이 필요하면 데스크톱 앱 설치.

### STEP 1. 나에 대해 알려 주는 문서 만들기 (2시간)
직접 쓰지 말고 클로드가 질문하고 내가 답, 문서는 클로드가 작성. 폰 앱에서 말로 답하면 더 빠르고 내용도 많아짐.
1. 새 대화에 인터뷰 프롬프트를 붙여넣기. 성공하면 "1/50" 번호가 붙은 첫 질문 하나만 옴.
   - 프롬프트 뼈대: 역할=About Me 문서를 만들기 위한 인터뷰어. 질문 50개를 한 번에 하나씩, 답하기 전엔 다음으로 안 넘어감. 10개 영역을 이 순서로 영역당 5개: 일, 비즈니스, 목표, 프로젝트, 사람, 원하는 답변 방식, 나의 말투, 도구, 생각하는 방식, 삶. 규칙: 메시지당 질문 하나·짧게, 모호하면 꼬리 질문 하나, 번호(12/50) 표기, "건너뛰기"면 다음으로. 끝나면 제목 10개(나는 누구인가 · 하는 일과 돕는 사람 · 목표(올해, 앞으로 90일) · 진행 중인 프로젝트 · 핵심 인물 · 원하는 답변 방식 · 나의 말투 · 쓰는 도구 · 생각하는 방식 · 절대 하지 말 것)로 1,200단어 이내 문서 작성, 내가 쓴 표현을 최대한 살림.
   - (사이트의 복사용 프롬프트는 추가로 [내 목표] 슬롯, 지어내기 금지, 문서 제시 전 자체 검증을 넣은 변형.)
2. ❌ "마케팅 일 해요." ✅ "쇼핑몰 광고를 맡고 있고, 매주 월요일에 지난주 성과 보고서를 씁니다." 답에 예시·숫자·이름을 넣을 것.
3. 90분 넘으면 "남은 질문은 빠르게 진행해 줘". 50개 끝나면 내 말처럼 읽힐 때까지 고쳐 달라고 하기.
4. 확인 프롬프트: `제목 10개가 모두 있는지, 1,200단어 이내인지 확인해 줘`
5. 완성본을 구글 문서/메모 앱에 `About Me`로 저장. 설정의 Your Claude(옛 화면 Memory)에서 Memory from chats 켜짐 확인.

질문 50개 (영역별 5개, 미리 메모해 두거나 통째로 붙여 한 번에 답해도 됨):
- 일: 무슨 일을 하나 / 누구를 돕나 / 평소 일주일 / 무엇으로 가장 알려졌나 / 시간을 가장 잡아먹는 일
- 비즈니스: 어떻게 돈 버나 / 무엇을 팔거나 제공하나 / 팀에 누가 있나 / 경쟁자 / 나만의 차별점
- 목표: 올해 목표 / 90일 목표 / 큰 성공의 모습 / 발목 잡는 것 / 그만두고 싶은 일
- 프로젝트: 지금 하는 작업 / 가장 중요한 프로젝트 / 다가오는 마감 / 계속 미뤄지는 일 / 방금 끝낸 일
- 사람: 자주 함께 일하는 사람 / 보고 대상 / 이상적인 고객 / 조언을 믿는 사람 / 배우는 사람
- 원하는 답변 방식: 짧은 vs 자세한 / 글머리표 vs 문단 / 짐작 전에 물어야 하나 / 직설 정도 / 절대 하지 말 것
- 나의 말투: 말투 표현 / 너무 자주 쓰는 단어 / 싫어하는 단어 / 좋아하는 글 쓰는 사람 / 격식체 vs 편한 말투
- 도구: 매일 쓰는 앱 / 메모 위치 / 할 일 위치 / 아직 손으로 하는 일 / 자동화하고 싶은 일
- 생각하는 방식: 결정 방식 / 가장 일이 잘되는 때 / 미루는 것 / 강점 / 약점
- 삶: 사는 곳 / 중요한 가치 / 일 밖의 활동 / 좋은 하루 / 그 밖에 알아야 할 것

### STEP 2. 세컨드 브레인 세팅 (3시간)
세컨드 브레인 = 내 정보와 진행 중인 일을 모아 두는 공간 하나. 클로드가 찾아 읽고 답에 씀.
1. 공간 선택:
   - 노션: 간단·여러 기기. 클로드 노션 커넥터로 접근
   - 옵시디언: 내 컴퓨터 파일. 데스크톱 앱 확장으로 폴더 연결(STEP 4)
   - 구글 드라이브: 이미 구글 문서로 일할 때. 구글 드라이브 커넥터
2. 칸 7개 생성 (노션=페이지, 옵시디언/드라이브=폴더):
   - `00 About Me`: STEP 1 문서
   - `Projects`: 프로젝트마다 한 페이지(목표, 마감, 상태, 링크)
   - `Areas`: 계속 이어지는 영역(일, 비즈니스, 건강, 가족, 돈)
   - `Tasks`: 할 일 목록 하나(항목마다 프로젝트·마감일)
   - `Docs`: 매뉴얼·템플릿·브랜드 가이드 등 다시 쓰는 것
   - `Notes / Inbox`: 미정리 메모
   - `Archive`: 끝난 프로젝트(지우지 말고 이동만)
3. 채우기는 클로드에게. 15분 동안 지금 하는 일을 전부 쏟아냄.
   - 프롬프트 뼈대: [About Me 첨부], [노션/옵시디언/구글 드라이브], 칸 7개를 알려 주고 내가 쏟아낸 일을 칸별로 분류. 프로젝트마다 이름·목표·마감·상태·다음 행동, 할 일마다 할 일·프로젝트·마감일. 겹치거나 그만둬도 될 프로젝트 표시, 둘 곳이 불확실하면 질문. 슬롯: [쏟아내기].
4. 결과를 내 공간에 옮겨 저장. 노션/드라이브는 https://claude.ai/customize/connectors 에서 연결. 연결 후 새 대화에서 "진행 중인 프로젝트가 뭐야?"에 내 목록이 나오면 완료.

### STEP 3. 실제 업무를 프로젝트로 옮기기 (2시간)
프로젝트 = 클로드 안의 작업 공간. 대화·파일·지침을 따로 갖고, 안의 내용을 모든 대화가 먼저 읽음.
1. 영역 정하기: 보통 4~6개(일, 비즈니스, 콘텐츠, 건강, 가족, 돈). 무료 플랜은 5개 한도라 5개 안으로 묶기.
2. 왼쪽 사이드바 프로젝트 메뉴에서 영역마다 프로젝트 생성.
3. 자료에 About Me와 그 영역의 핵심 파일 2~5개 업로드.
4. 프로젝트 화면의 지침(Instructions) 칸(대화 입력창 아님)에 템플릿 입력.
   - 지침 템플릿 뼈대: 이 프로젝트의 용도[영역] / 나는 누구인가: 프로젝트 파일의 About Me 참조 / 지금 중요한 것: 현재 목표[한 줄], 진행 프로젝트[2~4개], 마감[날짜] / 돕는 방법(말투, 답 끝에 다음 행동 하나 제안, 짐작 전에 질문 등) / 절대 하지 말 것(이모지, 요청 없이 300단어 초과 등).
5. 이번 달 아무 대화창에서 했던 일 3개를 맞는 프로젝트 안에서 다시 해 보기. 성공하면 새 대화에서도 목표·마감을 알고 답함.
- ❌ 프로젝트 밖 새 대화에서 "보고서 써 줘" ✅ 일 프로젝트 안에서 "이번 주 보고서 써 줘"

### STEP 4. MCP로 앱 연결 (2시간)
MCP = 앱을 클로드에 꽂는 표준 방식. 앱에선 커넥터로 보이고 한 번 로그인하면 어느 대화에서든 검색·읽기 가능.
1. https://claude.ai/customize/connectors 에서 Connectors 옆 `+`로 목록 열기.
2. STEP 1의 "매일 쓰는 앱" 중 3개만 연결.
3. 연결한 커넥터의 Tool permissions: 읽기는 `Always allow`, 보내기·올리기·지우기·결제 등 밖으로 나가는 동작은 `Needs approval`.
4. 프로젝트 안에서 앱마다 확인 프롬프트:
   - 지메일: `이번 주에 답장 안 한 메일을 요약하고 중요한 3개에 답장 초안을 써 줘`
   - 캘린더: `이번 주 일정이 어때? 회의마다 한 줄 브리핑을 준비해 줘`
   - 노션: `내 Projects 페이지를 읽고 가장 위험한 프로젝트를 알려 줘`
   - 구글 드라이브: `내 Projects 문서를 찾아 읽고 가장 위험한 프로젝트를 알려 줘` (읽기/검색용, 고친 내용은 내가 옮겨 저장)
   - 슬랙: `금요일 이후 [채널]에서 놓친 내용을 정리해 줘`
   - 할 일·디자인 툴: `이번 주 마감인 할 일을 프로젝트별로 묶어 보여 줘`
5. 옵시디언 등 로컬 폴더: 데스크톱 앱 설정의 Desktop app 항목 → Extensions 옆 `Manage` → `Browse extensions`에서 Filesystem 확장 `Install` → 설정의 허용 폴더(Allowed Directories)에 옵시디언 폴더 지정.
6. 통합 확인 프롬프트 뼈대: About Me, 세컨드 브레인, 연결 앱을 써서 다음 주 캘린더·메일·할 일을 보고 (1) 가장 중요한 3가지와 이유 (2) 밀릴 위험 일 (3) 월요일 오전 시간대별 계획. 성공하면 실제 일정·메일 제목이 들어간 계획이 나옴.
- 무반응이면 커넥터 연결 해제 후 재연결, 프롬프트에 "지메일에서"처럼 앱 이름 명시.

### STEP 5. 스킬 설치하고 진짜 결과물 만들기 (3시간)
스킬 = 한 가지 일을 내 방식대로 가르친 지시문 묶음, 해당 일이 나올 때만 불려옴. 주말 중 가장 많은 시간을 여기에.
1. 스킬 켜기(45분): 설정 Capabilities(한글 '기능')에서 `Code execution and file creation`(새 화면 `Create and edit files`) 아래 '클라우드에서 코드 실행' 토글 ON. 스킬 사용에 필수.
2. https://claude.ai/customize/skills 에서 쓸 스킬 켜기. 워드/엑셀/파워포인트/PDF 스킬은 요청에 맞춰 자동 사용.
3. 같은 목록에서 `skill-creator` 켜기(대화로 스킬 제작). 목록에 없으면 새 대화에서 "스킬 만드는 걸 도와줘".
4. 가장 자주 반복하는 일로 첫 스킬 제작.
   - 프롬프트 뼈대: skill-creator를 쓰라고 지시, 슬롯 [반복하는 일], 내가 지금 그 일을 어떻게 하는지 인터뷰(순서, 잘된 결과 기준, 최고 예시, 피할 실수) → 스킬 작성·보여주기·설치 도움.
5. 내려받은 스킬 파일은 Customize > Skills 탭의 `+` → `Create skill` → `Upload a skill`로 업로드.
6. 스킬이 안 불리면 프롬프트에 스킬 이름을 넣고 스킬 설명에 사용 시점을 분명히.
7. 결과물 하나 만들기(2시간): 매주 반복하는 일 3개 중 하나를 골라 오늘 돌아가는 가장 작은 버전만.
   - 프롬프트 뼈대: 슬롯 [만들 것], [쓰는 사람과 때], [입력], [출력]. 필요시 About Me·연결 앱 사용. 가장 단순한 버전과 사용법 제시, 써 본 뒤 고칠 점 질문.
- ❌ 반쯤 만든 것 5개 ✅ 하나만 골라 오늘 한 번 실제로 쓰고, 거슬린 점 하나 고친 뒤 월요일 캘린더에 넣기

## 주말 뒤 프롬프트 10개 (맞는 프로젝트 안에서 사용)
1. 아침 브리핑(매일): 오늘 캘린더·메일·할 일을 확인해 가장 중요한 3가지, 준비할 것, 빼도 되는 일 하나
2. 주간 리뷰(금요일): 끝낸 일, 밀린 일과 이유, 다음 주 위험 일 정리 + Projects 상태 갱신
3. 내 말투로 쓰기: About Me '나의 말투' 참고해 [대상]에게 [글] 작성, 나답지 않은 문장 표시

## 핵심 팁 · 주의사항
- 프로젝트 밖 대화는 늘 처음부터 시작 → 업무는 프로젝트 안에서.
- 프로젝트 파일이 많으면 답이 엉뚱해짐 → 파일을 더 넣지 말고 오래되거나 주제 다른 파일부터 제거. 좋은 파일 5개가 아무 파일 50개보다 낫다.
- 이번 주말에 세컨드 브레인 도구를 갈아타면 주말이 날아감.
- 클로드는 읽는다고 늘지 않음, 직접 실행해야 배움.
- 외부로 나가는 커넥터 동작(보내기·삭제·결제)은 승인 필요로.
- 세팅은 최신일 때만 유용 → 유지 루틴 필수.

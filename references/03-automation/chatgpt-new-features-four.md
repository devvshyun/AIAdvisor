# 아무도 모르는 ChatGPT 신기능 4개 세팅하는 법
- 원문: https://lazyowen.com/guides/chatgpt-new-features-four
- 도구·주제: ChatGPT (Word 추가 기능, dots, 스페이스, 스티커팩) · 신기능 세팅 (자동화, 프롬프트, 12분 읽기, STEP 4개, 약 18분 실습, 2026-10-20 공개)
- 한 줄 요약: 워드 안의 ChatGPT, 앱을 닫아도 일하는 dots, 함께 쓰는 스페이스, 셀카 스티커팩을 켜는 곳과 요청 문장, 요금제별 가능 여부를 정리했다.

## 언제 쓰나
- 새 ChatGPT 기능들을 어디서 켜고 어떻게 요청하는지 몰라 막막할 때. 네 기능은 서로 이어지지 않으니 하나씩 켜고 결과 확인 후 다음으로.

## 준비물 / 필요 도구
- ChatGPT https://chatgpt.com · 도움말 https://help.openai.com · dots https://chatgpt.com/dots
- Word 추가 기능(add-in): https://marketplace.microsoft.com/en-us/product/office/WA200010215 (엑셀·파워포인트에도 함께 설치됨)
| 기능 | 요금제 | 쓰는 곳 |
|---|---|---|
| 워드 추가 기능 | 무료 포함 모든 요금제 | 마이크로소프트 워드(회사·학교·개인 MS 계정) |
| dots | Pro(만 18세 이상, EEA·스위스·영국 제외), Business Premium, Enterprise(관리자가 켠 경우) | 폰 앱, 데스크톱 앱, PC 브라우저 (폰 브라우저 불가) |
| 스페이스 | Pro, Business, Enterprise | 웹, 데스크톱 앱 (폰은 읽기·공유만) |
| 스티커팩 | 모든 사용자 | 최신 폰 앱 |
- dots는 계정별 순차 공개라 요금제가 맞아도 메뉴가 안 보일 수 있음. 회사 워크스페이스는 관리자 설정으로 dots·스페이스 공유가 꺼져 있을 수 있음.
- 모두 OpenAI의 서비스 기능(오픈소스 아님).

## 단계별 방법
### 보조 프롬프트: 내 요금제에서 되는 기능 하나 골라 첫 결과 만들기 (프롬프트 뼈대)
- 역할: 4개 기능 세팅 안내 담당. 슬롯: [먼저 써 볼 기능과 하고 싶은 일 한 가지].
- 작업: 목표에 맞는 기능 하나 선택 + 요금제·기기 조건을 최신 공식 도움말 기준으로만 안내 → 화면에서 기능을 찾았는지 확인, 안 보이면 요금제·앱 버전·워크스페이스 설정 점검 → 한 단계씩 안내해 작은 결과 하나 완성 → 다음 요청 문장 두 개.
- 제약: 비밀번호·인증코드·계좌·주민번호 요청 금지, 화면을 못 보면 그렇다고 말하고 메뉴 이름 지어내지 않기, 결제·구매·예약·양식 제출 금지, 확인 안 된 연결/공유/예약/설치를 완료라 하지 않기.
- 검증: dots는 `방금 만든 확인 작업의 출처, 확인 주기, 시간대, 알림 받을 곳, 다음 확인 시각, 현재 상태를 보여줘.`, 워드는 이름·날짜·숫자 보존, 스페이스는 상대 접근, 스티커는 메시지 앱 표시 확인.

### STEP 1. 워드에 ChatGPT 넣기 (5분)
1. Marketplace 링크에서 `Get it now`
2. MS 계정 로그인(회사·학교·개인 모두 가능)
3. 설치 마치기(엑셀·파워포인트에도 같이 들어감)
4. 워드 리본 메뉴에서 ChatGPT 열기 → ChatGPT 계정 로그인(회사 워크스페이스면 해당 워크스페이스 선택)
5. 문서 오른쪽 ChatGPT 창 맨 아래 `Ask anything` 입력칸에 요청. 특정 문단만 고칠 땐 먼저 선택.
- 처음엔 연습용 사본에서 문단 하나만. 중요한 문서는 크게 고치기 전 사본 저장.
- ❌ `더 좋게 고쳐줘` (지킬 것을 몰라 약속·숫자까지 바뀜)
- ✅ 프롬프트 뼈대: 선택한 문단을 처음 읽는 사람도 이해하게 다시 쓰기, 톤은 분명·따뜻·간결, 이름·숫자·사실 주장·약속은 하나도 변경 금지, 뜻 유지·불필요한 전문용어만 제거, 뜻이 애매한 문장은 바꾸기 전에 먼저 알리기.
- 메모만 있는 문서 → 기획안 초안 뼈대: 문서 메모로 한 장짜리 프로젝트 기획안(목표, 대상, 결과물, 일정, 담당, 남은 질문), 문서에 있는 정보만 사용, 미정은 지어내지 말고 `확인 필요` 표시, 기존 제목 유지.
- 점검: 고친 문단을 원문과 비교(예: "전달을 목표로"가 "전달을 보장"으로 바뀌었으면 되돌리기).
- 한계: 이전 채팅/메모리는 이어받지 않음 → 말투·배경은 요청에 직접 적기. 열린 문서만 보고 PC의 다른 파일은 못 읽음 → 참고 내용 붙여넣기. 복잡한 표·차트 서식은 수동 보정.

### STEP 2. dots에게 계속 지켜볼 일 맡기기 (5분)
dots = 자기 클라우드 컴퓨터를 가진 ChatGPT 에이전트. 대화가 끝나거나 내 기기가 꺼져도 일을 이어 감.
1. 폰 앱/데스크톱 앱/PC 브라우저 중 하나에서 https://chatgpt.com/dots 열기
2. 이름과 모습 정하기
3. 첫 일에 필요한 앱만 연결(나중에 해도 됨). dots는 연결 앱 정보를 스스로 읽고 기억함.
4. 폰 설정에서 ChatGPT 앱 알림 허용
5. 폰 앱 Customize → Custom rules에서 공유·구매·접근 규칙을 `Ask before taking action`(하기 전에 묻기)로
- ❌ `이거 계속 지켜보다가 알려줘`
- ✅ 감시 요청 뼈대: 공개 페이지 [URL]에서 [신경 쓰는 변화: 새 행사 날짜/신청 시작/가격이 X원 아래], 평일 오전 9시 [시간대] 기준 확인 → 먼저 접근 가능 여부와 현재 상태를 기준으로 제시 → 조건 충족·큰 변화·문제 때만 알림(출처 링크·확인 시각·바뀐 내용 포함) → 구매·예약·양식 제출·연락 금지 → 저장된 설정·다음 확인 시각·알림 받을 곳 확인해 보고, 못 하면 켜졌다고 하지 말고 이유 설명.
6. 저장 확인 프롬프트 뼈대: 방금 만든 작업의 출처·확인 주기·시간대·알림 받을 곳·다음 확인 시각·현재 상태 표시, 내 컴퓨터가 켜져 있어야 하는지 답변, 가능하면 지금 한 번 확인 실행(출처·시각 포함), 저장 안 했으면 분명히 말하기, 같은 일정 중복 생성 금지.
7. 성공: 답에 저장 상태와 다음 확인 시각이 나오고 dots 프로필의 `Scheduled`에 작업 표시, 첫 실행 때 폰 알림 수신.
8. 알림이 많으면 조건 좁히기 뼈대: [구체적 조건]일 때만 알리도록 변경, 출처·일정 유지, 저장 확인, 변경 불가 시 내가 할 일 안내, 작업 중복 생성 금지. 성공 시 Scheduled에 작업이 하나만 유지.
- 일시 중지: 프로필 ••• → `Pause`. `Reset`은 대화·기억·예약 작업을 전부 삭제 → 결과 저장 후에만.

### STEP 3. 스페이스 하나 만들어 같이 쓰기 (5분)
스페이스 = 페이지와 파일을 프로젝트별로 모아 두는 공간, 페이지 = 함께 고치는 문서. 웹/데스크톱에서.
1. 생성: `'주말 여행'이라는 이름으로 스페이스를 만들어줘.` → Space 화면에서 확인
2. 첫 페이지 뼈대: [스페이스 이름]에 [프로젝트 이름] 페이지 생성, [메모 붙여넣기]를 목표·정해진 결정·할 일·담당·날짜·남은 질문으로 정리, 미정 담당·마감은 지어내지 않기, 출처 링크 유지, 무엇을 어디 저장했는지 보고.
3. 공유: 페이지 열기 → `Share` → 사람 추가, `view`(읽기) 또는 `edit`(편집) 선택 → 상대에게 열리는지 확인.
4. 공동 편집 요청 뼈대: 공유 페이지 검토, 정해진 결정은 유지하고 '남은 질문'만 수정, 프로젝트를 늦출 빠진 정보 찾고 다음에 답할 질문 3개 제안, 누구에게도 새 약속을 떠넘기지 않기. 편집 권한자끼리는 각자 ChatGPT로 실시간 공동 편집 가능.
- 개인 채팅/메모리는 공유되지 않지만 페이지 내용은 열람 가능자 모두에게 노출 → 개인정보 먼저 확인.
- 상위 페이지를 공유하면 하위 페이지도 같이 공유. 사람을 뺄 때는 상위 페이지와 스페이스 공유 설정 모두 변경. 링크로 건 파일은 원래 권한을 그대로 따름.

### STEP 4. 셀카로 스티커팩 (3분)
1. 폰 ChatGPT 앱 최신 버전 업데이트
2. 새 대화에서 얼굴이 안 가려진 밝은 셀카 업로드(홈 화면/이미지 메뉴의 스티커 템플릿으로 시작해도 됨)
3. ❌ `스티커 만들어줘` ✅ 뼈대: 셀카로 닮은 만화 스티커팩, 표정 6개(웃음, 축하, 이마 짚기, 고마워, 깜짝 놀람, 지침), 헤어·얼굴 특징·전체 모습 유지, 같은 그림체, 표정 크고 읽기 쉽게, 깔끔한 테두리, 포즈 다르게, 작은 디테일 제외, 글자 없이 표정만으로 전달.
4. 안 닮으면 수정 뼈대: 캐릭터와 그림체 유지, 얼굴을 셀카와 더 닮게(특히 [닮지 않은 부분]), 작은 크기에서도 표정 식별, [바꿀 스티커]만 변경. 한 곳만 고칠 것.
5. 마무리: 팩 다운로드 또는 지원 폰에서 아이메시지·왓츠앱에 추가(선택지는 기기마다 다름), 보내기 전 스티커를 메시지 크기로 열어 표정 확인(안 보이면 더 단순하게 재요청).

## 문제 해결
| 증상 | 조치 |
|---|---|
| 기능이 안 보임 | 요금제, 나라, 앱 버전, 회사 워크스페이스 설정 확인 후 세팅 재시도 |
| 워드에 ChatGPT가 없음 | 회사 계정이면 관리자가 ChatGPT 추가 기능을 허용해야 함 |
| 워드가 너무 많이 바꿈 | 더 짧은 부분만 선택, 지킬 사실·말투를 요청에 적기 |
| dots 알림 과다 | 알림 받을 정확한 조건 지정 |
| dots가 "지켜볼게요"만 함 | 저장 상태, 다음 확인 시각, 완료된 실행 1회를 보여 달라고 요청 |
| 같이 쓸 사람이 페이지를 못 엶 | 상대 계정과 페이지·스페이스 공유 설정 재확인 |
| 스티커가 안 닮음 | 안 닮은 한 부분만 집어 그 부분만 수정 요청 |

## 핵심 팁 · 주의사항
- 첫 답 하나로 판단하지 말고 "더 좋게"보다 "사실은 그대로, 첫 문장은 짧게, 다음 할 일은 더 분명하게"처럼 지킬 것/바꿀 것을 명시.
- ❌ "지켜볼게요"라는 말만 믿기 ✅ 저장 상태·다음 확인 시각·실행 기록 확인.
- 개인정보가 든 페이지 공유 주의, 타인 사진으로 스티커를 만들 때 사전 허락(초상권).
- dots는 연결한 앱 정보를 읽고 기억 → 필요한 앱만 연결, 구매·공유는 사전 확인으로.

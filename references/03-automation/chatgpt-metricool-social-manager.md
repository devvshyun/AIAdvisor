# ChatGPT로 SNS 관리
- 도구·주제: ChatGPT 앱(Metricool for Social Media) · Metricool · SNS 분석/예약 자동화
- 한 줄 요약: ChatGPT에 Metricool 앱을 연결해 SNS 성과 분석, 콘텐츠 아이디어, 게시물 예약을 대화로 처리하는 5단계(프롬프트 10개). (2026-10-05 갱신, 읽는 데 12분, 따라 하면 약 20분)

## 언제 쓰나
- 여러 SNS 계정의 성과를 묻고, 최적 게시 시간을 확인하고, 캡션 포함 예약까지 대화창 한 곳에서 하고 싶을 때
- ChatGPT가 SNS에 직접 로그인하는 게 아니라 Metricool을 거쳐 데이터를 읽고 예약하는 구조

## 단계별 방법
**Quick Start**: 로그인한 브라우저에서 앱 링크를 열면 Connect 버튼이 보임.

1. **STEP 1 앱 찾기 (2분)**: chatgpt.com 로그인 → 사이드바 `Apps`(화면에 Plugins로 보이면 그 메뉴) → `Metricool` 검색 → `Metricool for Social Media` → Connect 버튼 확인.
   - Apps 메뉴가 없으면: 요금제·지역·회사 워크스페이스(팀·기업 요금제의 관리자 승인 제한) 때문일 수 있음 → 앱 링크로 직접 열기 → 안 되면 OpenAI 도움말에서 사용 조건 확인.
2. **STEP 2 로그인·권한 (3분)**: Connect → `Sign in with Metricool for Social Media` → 계정이 없으면 여기서 가입(무료·카드 불필요) → 권한 화면에서 `Grant access`. 이 허용은 Metricool에 직접 로그인한 것과 비슷한 넓은 권한. 성공하면 입력창에서 `@` 또는 `+`로 앱 선택 가능.
3. **STEP 3 SNS 계정 연결 (5분)**: 연결 화면(위 링크)에서 플랫폼 클릭 → 해당 계정으로 로그인하고 요청 권한을 **전부** 허용(일부만 허용하면 기능 오작동) → 틱톡·유튜브 등 반복. 브랜드 = 계정을 묶는 단위(네트워크마다 계정 1개).
   - 인스타는 프로페셔널(비즈니스/크리에이터) 계정만. 개인 계정이면 인스타 앱 설정에서 먼저 전환.
   - 인스타 로그인 연결: 예약·발행 가능, 기본 지표만. 페이스북 연결: 인스타가 페이스북 페이지에 연결돼 있어야 하며 모든 기능 사용 → 성과 분석을 제대로 쓰려면 이쪽. 연결 방식을 나중에 바꾸면 새 연결로 취급돼 이전 기록이 안 보이므로 처음에 하나로 정할 것.
   - 연결 확인: 새 대화에서 `@`로 Metricool 선택 후 (읽기만 함)
   ```
   메트리쿨에 연결된 브랜드와 소셜 계정 목록을 보여줘
   ```
   → 내 인스타·틱톡 계정 이름이 보이면 성공. 비어 있으면 Metricool에서 계정 연결부터 다시.
4. **STEP 4 아이디어·성과 분석 (5분)**: 요청에 **기간 + 플랫폼 + 원하는 결과** 세 가지 포함. 보내기 전 `@`로 Metricool 선택. 한국어 문장을 그대로 써도 됨(원문엔 영어 원문도 병기). 아래는 10개 중 ①~⑥의 프롬프트 뼈대:
   - ① 최근 30일 내 최고 반응 콘텐츠 + Metricool의 경쟁 계정 데이터를 보고, 잘 되는 주제·형식 기반 새 아이디어 10개
   - ② 지난 1주일간 AI(내 주제로 교체 가능) 관련 반응 좋았던 콘텐츠 분석 → 다음에 만들 아이디어 10개
   - ③ 인스타 최근 30일 분석 데이터에서 상위 게시물 + 공통점 설명
   - ④ 최근 30일 인스타 vs 틱톡 성과 비교(어느 쪽이 더 빨리 성장하고 어떤 콘텐츠가 이끄는지)
   - ⑤ 내 팔로워 데이터 기준 이번 주 인스타 최적 게시 시간(플랫폼 교체 가능)
   - ⑥ 추적 중인 경쟁 계정 중 이번 달 가장 반응 좋은 게시물, 주제·형식·패턴 분해(경쟁 계정 등록 시에만)
   - ❌ "요즘 뭐가 잘 돼?"(데이터 없이 일반론) → ✅ "메트리쿨로 최근 30일 인스타 성과를 불러와서, 반응이 가장 좋았던 게시물과 공통점을 알려줘". 답에 게시 날짜·숫자가 붙어야 내 데이터를 읽은 것(Metricool 화면과 대조), 일반 조언만 나오면 기간·플랫폼을 넣어 재질문.
5. **STEP 5 예약·캘린더 확인 (5분)**: 영상 파일을 ChatGPT 대화창에 올린 뒤 요청. 예약 게시물은 그 시간에 실제로 올라가므로 캡션·영상·설정을 직접 확인.
   - ⑦ 이 영상을 내일 내 최적 게시 시간에 인스타그램과 틱톡에 예약(영어: "Schedule this video on Instagram and TikTok tomorrow at my best posting time.")
   - ⑧ 인스타그램 릴스로 내일 최적 시간에 예약 + `캡션은 이걸로: [캡션 붙여넣기]`(캡션·형식까지 내가 지정할 때)
   - ⑨ 최근 분석 데이터 기반 다음 7일 콘텐츠 계획(하루 아이디어 1개 + 플랫폼 + 최적 게시 시간). 이 단계에선 아직 예약 안 됨.
   - ⑩ 마음에 드는 계획을 예약으로 전환: "Turn this into my schedule for the week."
   - ❌ "이거 올려줘"(언제·어디가 없어 멋대로 정하거나 되물음) → ✅ 플랫폼·날짜·시간·형식·캡션 명시.
   - 확인: 답에 게시물 링크가 나오지 않으므로 Metricool 콘텐츠 캘린더에서 날짜별로 직접 확인(원문: Planning > Calendar 위치는 이 txt에 명시되지 않고 "콘텐츠 캘린더"로 표기).
   - 되돌리기: 날짜·시간·캡션 변경은 같은 대화에서 말하기 / 예약 삭제·첨부 수정은 Metricool 캘린더에서 직접 / 연결 해제는 ChatGPT 앱 설정.

**연결 확인 + 분석 위임 프롬프트 뼈대(새 대화 첫 메시지, `@Metricool` 선택 후)**: 역할=Metricool 연결 확인·성과 분석 담당, 맥락=앱을 방금 연결한 초보자(무료 플랜일 수 있음). 슬롯 `내 목표 = <Metricool로 먼저 하고 싶은 일 한 가지>`(계정·요금제·플랫폼은 묻지 말고 직접 확인). 작업: ① 브랜드와 연결 계정 목록 확인 ② 비어 있으면 멈추고 무엇을 연결할지만 안내 ③ 연결돼 있으면 최근 30일 인스타(없으면 다른 계정) 성과를 불러와 상위 게시물 3개와 공통점 정리 ④ 할 수 있는 일과 목표용 다음 요청 예시 2개. 제약: 예약·수정·발행 금지(읽기만), 확인 없이 설정 변경 금지, 로그인 정보·토큰 출력 금지. 출력: 브랜드/연결 계정, 기간, 상위 3개(날짜·숫자), 공통점, 예시 2개, 남은 오류. 검증: 계정 목록에 내 계정명이 보이고 상위 게시물의 날짜·숫자가 Metricool 화면과 일치.

## 핵심 팁 · 주의사항
- 연결 허용 = Metricool 직접 로그인에 가까운 넓은 권한. 믿는 곳에서만 허용하고 필요 없으면 ChatGPT 앱 설정에서 연결 해제.
- ❌ 무료 플랜에서 예약 테스트 남발(월 20개 한도에 포함), ❌ 경쟁 계정 즉흥 등록(5개, 등록 후 변경 불가) → 지켜볼 계정을 먼저 정하고 등록.
- ❌ 인스타 연결 방식을 나중에 변경 → 이전 기록 소실.
- ChatGPT 답만 믿지 말고 Metricool 캘린더에서 예약 확인.
- ChatGPT 요금제/지역/워크스페이스에 따라 Apps 메뉴가 없을 수 있음.

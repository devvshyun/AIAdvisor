# AI 오피스를 통째로 고용하는 법: 먼더 디플린
- 도구·주제: Munder Difflin (+ Claude Code / Codex / Antigravity) · 멀티 에이전트 관리 데스크톱 앱
- 한 줄 요약: 클로드 코드·코덱스 같은 AI 코딩 에이전트 여러 개를 사무실 화면 하나에 모으고, 팀장 에이전트 마이클에게만 말하면 마이클이 일을 나눠 맡기는 무료 앱의 설치·운영법. 챗봇이 아니고 AI 모델도 들어 있지 않다. (2026-10-08 공개, 읽는 데 13분, 따라 하면 약 33분)

## 언제 쓰나
- 자리를 비워도 알아서 일하는 AI 직원을 두고 싶은데 에이전트를 하나씩 챙기기 막막할 때
- 리서치, 콘텐츠, 코드 정리 등을 여러 에이전트에게 역할을 나눠 맡기고 진행을 한눈에 보고 싶을 때

## 준비물 / 필요 도구
- Munder Difflin (소스 MIT, 사무실 픽셀 그림은 별도 라이선스, HarnessMD 관리, GitHub 스타 8.5천+). 맥·윈도·리눅스
  - 사이트: https://munderdiffl.in/
  - 다운로드: https://harnessmd.com/download
  - GitHub: https://github.com/HarnessMD/munder-difflin
  - 릴리스(SHA256SUMS, portable.exe): https://github.com/HarnessMD/munder-difflin/releases
  - 설치 안내: https://munderdiffl.in/blog/how-to-install-and-use-munder-difflin/
- AI 코딩 에이전트 최소 1개(이미 내는 구독에 맞춰 하나 선택)
  - Claude Code (Claude Pro·Max): https://docs.claude.com/en/docs/claude-code
  - Codex (ChatGPT Plus·Pro, Node.js 필요): https://github.com/openai/codex
  - Antigravity (구글 계정): https://antigravity.google/docs/cli/install/

- 비용: 앱은 무료. 비용은 연결한 AI 구독 쪽에서 발생(기존 클로드·ChatGPT 구독 그대로). 유료 Pro 플랜은 회의 받아쓰기 등 추가 기능용이라 이 과정엔 불필요.
- 용어: 엔진 = 직원을 실제로 움직이는 AI 코딩 에이전트, LTS = 오래 지원하는 안정판, 토큰 = AI가 읽고 쓰는 글자 양 단위

## 단계별 방법
### 프롬프트 뼈대 A. 설치 준비·첫 브리핑 초안 위임 (이미 클로드 코드/코덱스가 있을 때, 터미널에서 실행 후 첫 메시지)
- 목적: 컴퓨터 점검 + 설치 파일 안내 + 마이클 첫 브리핑 초안 작성
- 역할: 먼더 디플린 설치 준비와 첫 브리핑 작성 도우미. 사용자는 개발 초보
- 슬롯: [내 목표 = 마이클에게 처음 맡길 일 한 줄] (예: 블로그 글 10개를 읽고 주제별 보고서). OS·칩·설치 도구는 직접 확인
- 작업: ① OS와 칩(애플 실리콘/인텔/x64) 확인 ② `claude --version`, `codex --version`으로 쓸 에이전트 확인(새 에이전트 설치 금지) ③ 공식 다운로드 페이지(https://harnessmd.com/download)에서 OS에 맞는 설치 파일 이름 안내, 맥에 이미 받았다면 `shasum -a 256 ~/Downloads/Munder-Difflin-*.dmg`로 릴리스 SHA256SUMS와 비교 ④ 목표를 결과·맥락·제약·질문 기준 4줄 브리핑으로 변환하고 다음 할 일을 안내
- 제약: 명령 실행 전 무슨 명령인지 설명, sudo·전역 설치·설정 파일 수정은 사전 질문, 토큰·비밀키 출력 금지, 기존 파일 덮어쓰기 금지
- 출력: 실행 명령, 버전, 받을 파일 이름, 지문 비교 결과, 브리핑 4줄, 남은 오류
- 검증: 쓰는 에이전트의 `--version`이 버전 숫자를 반환해야 함. 실패 시 완료 보고 금지

### Quick Start
맥은 애플 실리콘·인텔 공용 `.dmg`, 윈도는 `setup.exe`, 리눅스는 `.AppImage` 하나를 받아 설치. STEP 2를 마친 뒤 처음 열면 설정 마법사 화면. 나는 마이클에게만 말하고, 마이클이 일을 나눠 다른 에이전트에게 넘긴다.

### STEP 1. 내 컴퓨터에 맞는 설치 파일 받기 (3분)
Node.js나 소스 코드는 필요 없다. 설치만 하고 앱은 STEP 3에서 처음 연다(앱은 켜질 때 내 컴퓨터의 에이전트를 찾기 때문).
- 맥: `.dmg`를 열어 앱을 응용 프로그램 폴더로 끌어 넣기
- 윈도: `setup.exe` 실행. SmartScreen 경고가 뜨면 '추가 정보' → 실행. 막히면 릴리스 페이지의 `portable.exe`(설치 없이 열림)
- 리눅스: 받은 `.AppImage`에 실행 권한(성공하면 출력 없음)
```bash
chmod +x ~/Downloads/Munder-Difflin-*.AppImage
```
- 맥 정품 확인(선택): 아래 출력값을 릴리스의 `SHA256SUMS`에서 같은 파일 줄과 비교
```bash
shasum -a 256 ~/Downloads/Munder-Difflin-*.dmg
```
터미널은 맥 `Cmd+Space`로 '터미널', 윈도는 시작 버튼에서 'PowerShell'.

### STEP 2. AI 에이전트 하나 연결하기 (5분)
앱 안에는 AI가 없으니 구독에 맞춰 하나만 설치하고 로그인한다. 이미 있으면 설치 명령은 건너뛰고 버전 확인으로.
1. 클로드 코드(맥·리눅스)
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
윈도 PowerShell(Node.js 없이 설치)
```powershell
irm https://claude.ai/install.ps1 | iex
```
2. 코덱스: Node.js 먼저 확인, 없으면 nodejs.org에서 LTS 설치 후 터미널 재시작
```bash
node --version
npm install -g @openai/codex
```
앞의 `@openai/`를 빼면 전혀 다른 패키지가 깔리니 이름을 줄이지 않는다.
3. 안티그래비티(맥·리눅스): 설치 후 새 터미널에서 `agy` 실행 시 브라우저 로그인 화면
```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
```
윈도: `irm https://antigravity.google/cli/install.ps1 | iex`
4. 설치 확인(설치한 에이전트 줄만): `(Claude Code)` 또는 `codex-cli` 앞뒤로 버전 숫자
```bash
claude --version
codex --version
```
5. 설치와 로그인은 별개: 설치한 명령을 한 번 실행해 브라우저 로그인을 끝낸다. 클로드 코드는 `claude`(입력창이 뜨면 성공, 빠져나오기는 `/exit` 또는 `Ctrl+C` 두 번), 코덱스는 `codex`, 안티그래비티는 `agy`.

### STEP 3. 설정 마법사로 사무실 차리기 (5분)
1. 앱을 처음 연다. 맥은 "인터넷에서 받은 앱을 열까요" 창에서 열기. 리눅스는 실행 권한 준 `.AppImage`를 더블클릭.
2. 에이전트는 내 계정 권한으로 파일을 고치고 명령을 실행하므로, 첫 사무실은 새로 만든 빈 폴더에서 시작하고 홈 폴더 전체나 중요한 폴더는 고르지 않는다.
3. 마법사 항목: 앱 설정·기억 폴더(기본 제안 그대로 가능) → 마이클의 이름과 엔진(STEP 2에서 설치한 엔진이 "설치됨"으로 보여야 함, 아래 Model에서 모델 선택. 마이클은 계획·분배 담당이라 쓸 수 있는 가장 좋은 모델) → 에이전트가 일할 프로젝트 폴더(새 빈 폴더) → 권한 화면 맨 위 `LET AGENTS WORK ON THEIR OWN` 체크를 끄고 시작(꺼야 파일 변경·명령 실행 전에 먼저 묻는다. 몇 번 지켜본 뒤 켜도 늦지 않음).
4. 엔진이 "설치 안 됨"이면 앱을 완전히 끄고 다시 연다.
5. 마법사가 끝나면 사무실 화면에 마이클만 앉아 있다. 직원 추가는 `Add agent`(이름·엔진·모델·프로젝트), 준비 상태는 설정의 `Prerequisites`.

### STEP 4. 마이클에게 첫 일 맡기기 (10분)
마이클은 처음 출근한 유능한 신입처럼 대하고 끝났을 때의 모습만 또렷하게 말한다. 커맨드 센터 아래 `Message Michael` 칸에 브리핑을 붙여넣고 `send`.

프롬프트 뼈대 B. 마이클 브리핑 템플릿 (4줄)
- 결과: [끝나면 손에 쥘 것 한 가지] (예: 블로그 글 10개를 주제별로 묶은 보고서 한 장)
- 맥락: [누구를 위한 일이고 지금 무엇이 있는지] (예: 글은 posts 폴더, 독자는 AI 입문자)
- 제약: 돈이 나가는 일, 파일 삭제, 프로젝트 폴더 밖 작업은 하기 전에 먼저 물어볼 것
- 질문 기준: 내 결정이 꼭 필요할 때만 질문, 나머지는 알아서 나눠 진행, 끝나면 한 일과 남은 문제를 요약 보고

확인: 마이클이 일을 작은 작업으로 나눠 넘기면 책상 사이로 봉투가 날아가고, 책상을 누르면 그 에이전트의 터미널이 실시간으로 열려 바로 입력할 수도 있다. 되묻기만 반복하면 결과 줄을 더 구체적으로 고쳐 재전송. 다음 날 다시 열면 에이전트마다 배운 것을 기억하고 있어 이어서 시킬 수 있다.

### STEP 5. 역할을 나눠 팀 꾸리기 (10분)
같은 일을 5명에게 시키면 결과도 5번 겹치므로 처음엔 2~3명으로 시작한다.
1. 역할 예: 조사(정보 수집·정리) / 개발(실제 제작) / 리뷰(점검) / 테스트(실행해 문제 찾기)
2. `Add agent` 창의 `4 BRIEFING`에 역할을 한 줄로 적고 `3 ENGINE`에서 엔진·모델 선택. 엔진은 섞어도 됨: 단순 작업은 가벼운 엔진, 어려운 작업은 유료 구독 엔진.
3. 역할 분담 예: 리서치 = 조사/분석/보고서 작성 각 1명 / 콘텐츠 = 조사 → 기획 → 글쓰기 → 편집 → 검수 / 코드 정리 = "이 저장소에서 영향이 큰 문제를 찾아 고치고, 테스트한 뒤 바뀐 점을 요약해 줘"처럼 큰 목표 하나
4. 에이전트는 내 컴퓨터에서 돌아가니 자리를 비울 땐 컴퓨터를 켠 채로 두고, 밤새 맡기기 전 설정 `Autonomy & Budgets`의 `FLOOR TOKEN BUDGET`에 사무실 전체 토큰 상한을 적고 `save`(앱이 상한 초과를 막음).

## 핵심 팁 · 주의사항
- ❌ 설치만 하고 바로 먼더 디플린 열기(에이전트가 켜지자마자 꺼짐) → ✅ `claude`/`codex`/`agy`를 한 번 실행해 로그인까지 끝낸 뒤 앱 열기
- ❌ "내 스타트업 만들어 줘" → ✅ "내 자동화 상품 랜딩 페이지를 조사부터 화면, 구현, 테스트까지 끝내고 요약을 보내 줘. 내 결정이 꼭 필요할 때만 물어봐."
- 에이전트는 내 계정 권한으로 파일 수정·명령 실행 → 빈 폴더에서 시작, 처음엔 자율 실행 체크 끄기
- 프롬프트와 에이전트가 읽은 파일은 선택한 AI 서비스로 전송됨 → 회사 코드는 사내 규칙부터 확인
- 밤새 돌리기 전 토큰 예산 설정

## 문제 해결
- 에이전트가 켜지자마자 꺼짐: 로그인이 안 된 경우, 터미널에서 해당 명령을 한 번 실행해 로그인 완료
- 마법사에서 설치 안 됨: 앱 완전 종료 후 재실행
- 아무 일도 안 일어남: 오른쪽 Command Center에서 메시지 전달이 일시정지인지 확인
- 구독 없이 써 보기: 앱 설정 `AI Engines`에서 Ollama·LM Studio·vLLM 등 내 컴퓨터의 모델 연결(품질은 모델에 따름)

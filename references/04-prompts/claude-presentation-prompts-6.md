# 발표 자료 뽑는 클로드 프롬프트 6개
- 도구·주제: Claude (claude.ai) · 발표 자료(PPTX) 생성 프롬프트
- 한 줄 요약: 한 대화 안에서 설계도→슬라이드 구조→스토리→디자인→내용→다듬기 6개 프롬프트를 순서대로 보낸 뒤 .pptx 파일을 요청한다. (2026-10-19 공개, 읽는 데 8분, 5단계 약 14분)

## 언제 쓰나
- 청중·시간이 정해진 발표 자료를 PPT 없이 처음부터 구조화해 빠르게 만들고 싶을 때
- 꺾쇠(`< >`) 칸만 바꿔 붙여넣는 한국어 프롬프트 6개 + PPT 파일 받는 방법

## 준비물 / 필요 도구
- Claude: https://claude.ai/ (웹/데스크톱/모바일 앱, 앱 https://claude.ai/download). 앤트로픽 제작 웹 서비스(오픈소스 아님)
- 파일 생성 공식 도움말: https://support.claude.com/ko/articles/12111783-create-and-edit-files-with-claude
- '코드 실행 및 파일 생성' 기능 필요. 무료(Free) 포함 모든 요금제에서 사용 가능, 사용량 한도 차감(파일 생성은 일반 대화보다 많이 소모)
- 열어 볼 프로그램: PowerPoint / Google Slides / Keynote (.pptx)

## 단계별 방법
1. **STEP 1 파일 생성 켜기 + 주제 칸 정하기 (2분)**
   - 웹·데스크톱: 설정 > 기능 > 코드 실행 및 파일 생성 / 모바일: 사이드바에서 이니셜·이름 > 설정 > 기능 > 코드 실행 및 파일 생성 / Team·Enterprise: 메뉴가 잠겨 있으면 조직 관리자에게 요청. Free·Pro·Max는 기본 ON(꺼졌을 때만 켬).
   - 모든 프롬프트의 `<주제>` 칸에 넣을 한 줄에 **청중과 발표 시간**까지 적기. 예: `신입 사원 대상 보안 교육, 15분 발표`
   - ❌ `보안`처럼 단어 하나(청중·길이를 몰라 슬라이드 수와 말투가 엉뚱) → ✅ 청중+시간 포함. 회사 기밀·고객명·개인정보는 넣지 말 것.
2. **STEP 2 설계도·구조 (3분)**
   - **프롬프트 1 — 발표 설계도**: 역할=전문 발표 컨설턴트. 슬롯 `<주제>`. 요구: 핵심 목표, 대상 청중, 핵심 메시지, 슬라이드 흐름, 알맞은 슬라이드 수를 정하고, 구조는 논리적·몰입감·전문적으로. → 다섯 항목이 보이면 성공. 슬라이드가 많으면 "슬라이드는 10장 안으로 줄여 주세요"처럼 한 줄로 수정 요청.
   - **프롬프트 2 — 슬라이드 구조/흐름**: `<주제>` 발표를 슬라이드별 구조로 설계, 슬라이드마다 명확한 제목 + 목적 설명, 처음부터 끝까지 자연스럽게 이어지게. → 번호별 제목+목적 한 줄.
   - ❌ 프롬프트마다 새 대화(앞 설계도를 몰라 슬라이드 수·흐름이 바뀜) → ✅ 한 대화창에서 1~6을 순서대로 이어 보내기.
3. **STEP 3 스토리·디자인 (3분)**
   - **프롬프트 3 — 스토리텔링**: `<주제>`를 강한 스토리텔링 구조로 몰입형 발표로 변환. 구조는 훅 → 문제 → 인사이트 → 해결책 → 결론, 전문적·유익하고 감정적으로도 빠져들게. (훅=첫머리에서 관심을 붙잡는 한마디, 인사이트=문제에서 얻은 새 깨달음) → 다섯 단계로 묶이면 성공. 마음에 안 들면 같은 프롬프트 재전송.
   - **프롬프트 4 — 비주얼 방향**: 슬라이드마다 전문적인 비주얼 디자인 가이드 제안, 깔끔·모던·완성도 있게 보이도록 레이아웃·차트·다이어그램·아이콘·시각 자료 추천. → 슬라이드별 "왼쪽 글, 오른쪽 막대 차트" 식 배치가 정해지면 성공.
4. **STEP 4 내용 쓰기·다듬기 (4분)**
   - **프롬프트 5 — 슬라이드 내용**: `<주제>` 발표의 모든 슬라이드 내용을 바로 쓸 수 있는 간결한 불릿으로, 명확·전문적·이해하기 쉽게. 슬롯 `청중: <청중 설명>`.
   - **프롬프트 6 — 다듬기**: 아래 발표 내용을 검토해 슬라이드에 맞게 재작성: 불필요한 글 축소, 핵심 요점 강화, 명확성 향상, 슬라이드마다 아이디어 하나만. 슬롯 `내용: <다듬을 내용 붙여넣기>`(프롬프트 5의 답 또는 내 초안). → 한 장에 핵심 문장 하나 + 짧은 불릿만 남으면 성공.
   - ❌ "더 좋게 고쳐 줘"(기준 없어 글만 길어짐) → ✅ 프롬프트 6 그대로 사용.
   - 슬라이드의 숫자·사례는 발표 전 내 자료와 하나씩 대조.
5. **STEP 5 PPT 파일로 받기 (2분)**: 같은 대화에서 요청 — 위에서 다듬은 내용으로 `.pptx` 파일을 만들고, **슬라이드마다 제목 1개 + 불릿 5줄 이내**, 프롬프트 4에서 정한 디자인 방향을 따를 것.
   - 성공하면 대화창에 `.pptx`가 나타나 다운로드하거나 Google Drive에 저장 가능. 모바일은 '다운로드'로 기본 미리보기/별도 앱에서 열림.
   - 파일 대신 글만 나오면 STEP 1 설정 확인 후 재요청. 파일 크기 한도 하나당 30MB.
   - 받은 파일에서 글꼴·색·사진을 조직/학교 양식에 맞게 마지막 조정.

**통합 프롬프트 뼈대(첫 메시지 한 번에)**: 역할=발표 전체 제작 컨설턴트, 맥락=PPT 초보자. 슬롯 `내 주제 = <주제와 발표 시간>`, `청중 = <누가 듣는지>`. 작업: ① 목표·청중·핵심 메시지·흐름·슬라이드 수 설계도 ② 훅→문제→인사이트→해결책→결론으로 장별 제목·목적 + 레이아웃·차트·다이어그램·아이콘 방향 ③ 전 슬라이드 불릿 작성 후 한 장 한 아이디어로 다듬기 ④ `.pptx` 생성·다운로드 + 다음에 고칠 점 안내. 제약: 주지 않은 숫자·통계·회사명·사례는 지어내지 말고 `(내용 채우기)`로 비움, 슬라이드당 불릿 5줄 이하, 파일을 못 만들면 만든 척하지 말고 설정 > 기능에서 코드 실행 및 파일 생성을 켜 달라고 안내. 출력: 설계도 → 장별 제목·목적·디자인 → 다듬은 내용 → .pptx. 검증: 파일명이 `.pptx`, 슬라이드 수가 설계도와 같음, 장마다 제목과 아이디어 하나. 어긋나면 완료 보고 금지.

## 핵심 팁 · 주의사항
- 통합 프롬프트는 숫자·통계·사례를 지어내지 않고 자리표시자를 남기도록 설계 → 그래도 사실 확인은 직접.
- 말로만 "완료"하고 파일이 없는 경우를 막기 위해 다운로드 가능한 .pptx가 실제로 있는지, 슬라이드 수가 설계도와 같은지, 각 슬라이드에 제목이 있는지 확인.
- Free 플랜은 프롬프트 1~6을 먼저 끝내고 파일 요청은 한 번만(한도 절약).
- 기밀·고객명·개인정보 입력 금지.

# 어떤 화면 녹화든 모션 디자이너 작품처럼 만드는 레코들리 사용법
- 도구·주제: Recordly(레코들리) · 화면 녹화 / 모션 편집
- 한 줄 요약: 무료 오픈소스 데스크톱 앱 Recordly로 녹화를 멈추면 커서 따라가는 자동 확대가 잡히고, 부드러운 커서·배경 프레임·얼굴 버블까지 클릭 몇 번으로 입혀 MP4/GIF로 내보낸다. (검증 기준 v1.4.0, 2026-09-27, 약 17분)

## 언제 쓰나
- 앱 시연·제품 데모 영상이 밋밋하고 확대 구간을 손으로 잡느라 시간이 오래 걸릴 때
- 릴스/틱톡, 랜딩 페이지 영상, README/메일/슬랙용 GIF를 깔끔하게 만들고 싶을 때

## 단계별 방법
### 프롬프트 뼈대 A. 맥 설치·권한 점검 위임용 (선택, 터미널 가능한 AI에 붙여넣기)
- 목적: 맥에 Recordly 설치 확인 → 없으면 설치 → 권한·내보내기 설정 안내
- 역할: Recordly 설치·첫 녹화 준비 확인 담당, 사용자는 개발 초보
- 슬롯: [내 목표 = 처음 만들 영상 한 줄] (예: 인스타 릴스용 9:16 앱 시연 30초). OS·칩·설치 여부는 직접 확인
- 작업: ① `sw_vers -productVersion`, `uname -m`으로 확인(맥이 아니거나 macOS 14 미만이면 중단) ② `defaults read /Applications/Recordly.app/Contents/Info.plist CFBundleShortVersionString`로 설치 확인, 없을 때만 설치(`brew --version`이 되면 `brew install --cask recordly`, 아니면 최신 릴리스에서 arm64 = `Recordly-arm64.dmg` / x86_64 = `Recordly-x64.dmg` 받아 응용 프로그램으로 이동하도록 안내) ③ 설치 확인 명령 재실행 ④ 켤 권한 4개(화면 및 시스템 오디오 녹음, 손쉬운 사용, 마이크, 카메라)와 목표에 맞는 비율·내보내기 설정을 6줄 이내로 안내
- 제약: sudo·전역 설치·설정 수정·앱 설치 명령은 실행 전 질문, 비밀번호·키 출력 금지, 이미 있는 Recordly 덮어쓰기 금지, 권한 스위치는 사용자가 직접(위치만 안내)
- 출력: 실행 명령, macOS 버전·칩, 설치된 버전, 바뀐 파일, 남은 오류
- 검증: 위 `defaults read` 명령이 `1.4.0` 같은 버전 숫자를 반환해야 완료

### Quick Start
- 맥: `Recordly-arm64.dmg`(애플 실리콘) 또는 `Recordly-x64.dmg`(인텔)를 열어 Recordly를 Applications로 드래그
- 윈도우: `Recordly-windows-x64.exe` 실행
- 리눅스: 아래 "터미널로 설치하고 확인하기" 참고
앱을 열었을 때 녹화할 화면/창을 고르는 녹화 화면이 보이면 성공.

### STEP 1. 설치 파일 받기 (3분)
릴리스 페이지 Assets에서 고른다.
| 내 컴퓨터 | 받을 파일 | 설치 방법 |
|---|---|---|
| 맥 애플 실리콘(M으로 시작하는 칩 전부) | `Recordly-arm64.dmg` | 열고 Recordly를 Applications로 끌어놓기 |
| 맥 인텔 | `Recordly-x64.dmg` | 위와 같음 |
| 윈도우 10(19041+)·11 | `Recordly-windows-x64.exe` | 실행해서 설치 |
| 리눅스 | `Recordly-linux-x64.AppImage` | 터미널 절 참고 |
칩을 모르면 사과 메뉴 → '이 Mac에 관하여'에서 칩 이름 확인(M으로 시작하면 arm64). 이미 깔려 있으면 건너뜀.

### STEP 2. 맥 권한 네 개 켜기 (2분, 윈도우·리눅스는 건너뜀)
사과 메뉴 → 시스템 설정 → 개인정보 보호 및 보안에서 항목마다 Recordly를 켠다. 목록에 없으면 앱에서 녹화를 한 번 시작해 권한 요청 창을 먼저 띄운다.
| 항목 | 꺼져 있으면 |
|---|---|
| 화면 및 시스템 오디오 녹음 | 녹화가 안 되거나 화면이 까맣게 나옴 |
| 손쉬운 사용 | 커서를 못 따라가 자동 확대·커서 효과 무효(앱이 마우스 움직임을 읽는 권한) |
| 마이크 | 목소리 없이 녹화 |
| 카메라 | 얼굴 버블 사용 불가 |
켠 뒤 Recordly를 완전히 종료(창을 앞에 두고 `Cmd + Q`)하고 다시 연다. 다시 열지 않으면 앱이 인식하지 못한다.

### STEP 3. 녹화하고 확대 두세 개만 남기기 (5분)
1. Recordly를 열고 화면 전체나 창 하나 선택
2. 마이크·시스템 소리 녹음 여부를 고르고 녹화 시작(얼굴을 넣으려면 웹캠도 켬)
3. 버튼을 몇 번 누르고 보여 줄 곳에서 커서를 잠깐 멈춤
4. 녹화를 멈추면 편집기가 열림. 타임라인에서 돋보기 표시와 `1.5×` 같은 배율이 붙은 블록이 자동 확대 구간
5. 필요 없는 확대 블록은 눌러서 삭제, 놓친 곳은 미리보기 아래 도구 줄의 돋보기(+) 아이콘으로 추가
6. 커서 다듬기: 편집기 왼쪽 세로 아이콘 줄 두 번째(마우스 커서 모양)
| 설정 | 하는 일 | 추천 |
|---|---|---|
| 커서 보정(smoothing) | 떨리는 움직임 매끄럽게 | 켜기 |
| 클릭 바운스(click bounce) | 클릭 시 커서가 살짝 튐 | 켜기 |
| 모션 블러(motion blur) | 빠른 움직임에 잔상 | 그래도 떨리면 올리기 |
| 커서 크기(size) | 커서 확대 | 9, 릴스면 한 칸 크게 |
| 커서 반복(Loop cursor) | 반복 재생 시 끝과 처음이 깔끔히 이어짐 | 반복 GIF일 때만 켜기(패널 맨 위 '커서 표시' 옆 스위치) |

### STEP 4. 배경 프레임과 얼굴 버블 입히기 (4분)
처음 녹화하면 기본 배경·그림자·여백이 이미 입혀져 열린다(맥은 둥근 모서리도). 바꾸고 싶을 때만 조정.
1. 첫 번째 아이콘(마술봉)에서 프레임 설정(한국어 UI는 이름만 번역, 순서 동일)
  - 배경(BACKGROUND): Image·Video·Color·Gradient 선택, 복잡하면 Background Blur 올리기
  - 프레임(FRAME): Shadow(그림자), Radius(둥근 모서리)
  - 여백(PADDING): 녹화 화면 둘레 공간
2. 세 번째 아이콘(카메라)에서 얼굴 버블의 크기·위치·둥글기·그림자 조정. 웹캠 없이 찍었다면 따로 찍은 얼굴 영상을 올려 붙일 수 있음. 줌에 맞춰 크기가 변하는 `zoom-reactive`는 켜 둔다(끄면 화면만 커지고 얼굴은 그대로).
3. 무음 구간 자르기: 타임라인 위 가위 아이콘(단축키 `C`)으로 앞뒤를 나눔 → 조각을 누르면 왼쪽 패널에 클립 설정 → 빈 조각은 `Delete Clip`으로 삭제
4. 느린 구간(로딩 등): 조각 선택 후 같은 패널의 Speed에서 `2×` 같은 배속 선택

### STEP 5. 비율 골라 내보내고 저장하기 (3분)
비율은 편집기 오른쪽 위 `16:9` 메뉴에서 선택.
| 용도 | 비율 | 핵심 설정 | 내보내기 |
|---|---|---|---|
| 릴스·틱톡 | 9:16 | 창 하나 녹화, 확대 2~3개, 얼굴 버블 크게 | MP4, 가장 높은 품질 |
| 랜딩 페이지·데모 | 16:9 | 그라데이션 배경, 여백 넉넉히, 그림자, 얼굴 버블 없이 | MP4 + 가장 좋은 5초 GIF |
| README·메일·슬랙 | 자유 | 기능 하나만 5~8초, 커서 반복 켜기 | GIF, 반복 켜기 |
내보내기 순서:
1. 오른쪽 위 파란 Export 버튼 → MP4 또는 GIF
2. 같은 창에서 품질, GIF 프레임 속도, 반복, 출력 크기 설정
3. GIF가 무거우면 5~8초로 자르고 프레임 속도·출력 크기를 낮춤
4. 닫기 전 `File → Save Project…`(맥 `Cmd + S`, 윈도우 `Ctrl + S`)로 `.recordly` 프로젝트 저장(다른 비율로 다시 뽑을 때 편집 재작업 불필요)

### 터미널로 설치하고 확인하기 (선택)
리눅스 명령(chmod·AppImage·yay)은 프롬프트에 없으니 직접 실행한다.
1. 설치 여부(맥): 버전 숫자가 나오면 설치됨, `does not exist`로 끝나면 없음
```bash
defaults read /Applications/Recordly.app/Contents/Info.plist CFBundleShortVersionString
```
2. macOS 버전 / 칩 / 홈브루 확인: 첫 줄 14 이상, 둘째 줄 `arm64`=애플 실리콘 · `x86_64`=인텔, 셋째 줄이 `command not found`면 홈브루 없음(STEP 1 파일로 설치)
```bash
sw_vers -productVersion
uname -m
brew --version
```
3. 홈브루 설치 후 첫 확인 명령을 다시 실행
```bash
brew install --cask recordly
```
4. 리눅스 AppImage(받은 폴더에서; 첫 줄을 빼면 Permission denied)
```bash
chmod +x Recordly-linux-x64.AppImage
./Recordly-linux-x64.AppImage
```
5. 아치/만자로(공식 README 안내)
```bash
yay -S recordly-bin
```

## 핵심 팁 · 주의사항
- ❌ 잡힌 확대를 한 번도 안 보고 내보내기(비슷한 확대가 연달아 있으면 핵심 순간이 묻힘) → ✅ 보여 주고 싶은 순간 2~3개만 고르기
- ❌ 여백 0 + 그림자 끄기(배경에 딱 붙어 잘못 잘린 영상처럼 보임) → ✅ 여백 넉넉히 + 그림자 켜기(화면이 떠서 제품 화면처럼 읽힘)
- ❌ 모니터 전체를 녹화한 뒤 편집기에서 9:16으로 바꾸기(글자가 작고 흐려짐) → ✅ 녹화 전에 앱 창을 세로로 길게 줄이고 그 창만 녹화
- 권한을 켜고도 앱을 재실행하지 않으면 무효
- 무거운 GIF는 5~8초로 자르고 프레임 속도/크기를 낮춤

## 한계
- 확장 마켓플레이스는 현재 사용 불가: 2026년 8월 말 앱에서 제거, v1.4.0의 확장 칸(퍼즐 아이콘)에는 "Extensions are no longer available"만 표시. README가 예로 든 클릭 소리·기기 프레임·브라우저 목업도 막힘
- 자동 확대는 앱에서 녹화할 때 남긴 커서 기록으로 만들어짐. 다른 앱으로 찍은 영상을 불러오면 확대 추천이 없고(앱이 먼저 화면 녹화를 안내), 커서를 거의 안 움직인 녹화는 추천이 비어 있을 수 있음
- 리눅스는 실제 커서를 숨기지 못해 커서 효과를 켜면 진짜+꾸민 커서가 둘 다 찍힐 수 있고, 시스템 소리 녹음엔 보통 PipeWire 필요
- 윈도우 10 빌드 19041 미만은 녹화는 되더라도 실제 커서가 영상에 남을 수 있음
- 지금은 계정·유료 플랜 없음(단, 2026-09-23 최신 코드에 로그인 화면 작업이 올라와 다음 버전에 계정 화면이 생길 수 있음)
- 버튼 위치·이름은 v1.4.0 기준이라 다음 버전에서 바뀔 수 있음

# 클로드에서 쓰는 힉스필드 명령어 8개
- 원문: https://lazyowen.com/guides/higgsfield-commands-claude
- 도구·주제: Claude + Higgsfield MCP 커넥터 · 말하는 영상에 모션 그래픽 효과 입히기 (영상·이미지, 11분, 2026-10-30 갱신)
- 한 줄 요약: Higgsfield 커넥터를 Claude에 붙이고 `/tier-list` 등 8개 슬래시 명령어로 직접 찍은 말하는 클립에 그래픽 효과를 넣는다.

## 언제 쓰나
- 직접 찍은 말하는 영상에 티어표, 자막, 그래프, 머리 뒤 글자 같은 효과를 편집 앱 없이 빠르게 입히고 싶을 때

## 준비물 / 필요 도구
- 설치 프로그램 없음. claude.ai 웹 또는 Claude 데스크톱 앱. 커스텀 커넥터는 무료 요금제도 가능(무료는 1개까지)
- 힉스필드 계정(연결 시 로그인, API 키 불필요)
- 크레딧: 생성·재생성마다 소모. 신규는 MCP 3일 무료 체험(https://higgsfield.ai/s/higgsfield-commands-in-claude-ig-lazy-owen-mQAGKr)
- 촬영 클립(내가 말하는 영상, 효과마다 따로 찍어도 됨)
- 연결 페이지: https://higgsfield.ai/mcp?tab=claude · 힉스필드 도움말: https://higgsfield.ai/creator-hub/help-center/integrations/how-do-i-connect-higgsfield-to-ai-agent · 클로드 도움말: https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp
- MCP = AI 앱이 다른 서비스의 도구를 쓰게 하는 연결 방식(클로드에선 커넥터)

## 단계별 방법
### 연결 (처음 한 번)
가장 쉬운 길: 연결 페이지의 `Connect Higgsfield` 버튼 → 클로드 커스텀 커넥터 추가 창이 이름·주소가 채워진 채 열림(외부 링크 경고에서 대상이 mcp.higgsfield.ai인지 확인) → 아래 5번 Continue부터.

직접 입력:
1. Customize → Connectors
2. `+ Add` → `Add custom connector`
3. Name: `Higgsfield`
4. Remote MCP server URL에 입력 후 Continue:
```
https://mcp.higgsfield.ai/mcp
```
5. 클로드가 찾은 인증 설정은 바꾸지 말고 Continue
6. Authentication에서 `Sign in now` → `Add`
7. 힉스필드 로그인 창에서 로그인 → 커넥터 목록에 연결됨으로 표시
8. 확인: 새 대화에서 `내 힉스필드 크레딧 잔액이 얼마야?` → 숫자가 나오면 성공
- 모바일: 한 번 추가하면 휴대폰 Claude 앱에서도 사용. 대화 `+` → Connectors에서 Higgsfield 켜기
- 팀·기업 요금제: Owner가 조직 설정의 Connectors에 먼저 추가 → 이후 Customize → Connectors에서 Higgsfield 옆 `Connect`

### 사용 순서
1. 효과 절의 요청문 복사 → `[대괄호]` 칸을 내 내용으로 바꾸기(대괄호와 "예:"는 지우고 값만).
2. 새 대화에 붙여넣고 전송 → 대화 안에 열린 힉스필드 업로드 창에서 클립 선택.
3. 마음에 안 들면 고칠 점을 그대로 말함(예: "표를 조금 더 아래로 내려 줘.").
- ❌ 영상 파일을 채팅 입력창에 드래그앤드롭(힉스필드로 전달 안 됨) ✅ 요청문 먼저 보내고 열린 업로드 창에서 선택
- 비용 먼저 보려면 요청 끝에 `생성하기 전에 크레딧 비용을 먼저 알려 줘`

### 명령어 8개 (프롬프트 뼈대)
모든 요청문 공통 구조: `/명령어` + 효과 설명(내 값 슬롯) + "시작하기 전에 힉스필드 업로드 창을 열어 영상을 올리게 해 줘" + "힉스필드가 연결 안 돼 있으면 연결부터 안내해 줘".

1. `/tier-list` : 티어 표를 만들고 말한 도구를 로고와 함께 말한 등급 줄에 배치. 슬롯 [등급 방식 예: S/A/B]. 촬영 시 도구 이름+등급을 같이 말하기(❌ "요즘 AI 툴 많이 써요" ✅ "클로드는 S, 챗GPT는 A, [도구]는 B예요"). 성공: 도구가 로고와 함께 맞는 줄에 들어감.
2. `/text-behind` : 말하는 핵심 단어가 그 순간 머리 뒤에 나타나고 머리가 글자 일부를 가림. 슬롯 [핵심 단어 예: 조회수]. 또렷하게, 키워드 하나("결국 중요한 건 [키워드]예요").
3. `/grade-wipe` : 밋밋한 화면에서 시작해 빛 띠가 지나가며 색보정을 드러냄. 슬롯 [원하는 색감]. 얼굴 밝게 촬영. 성공: 빛 띠가 지난 쪽부터 색이 바뀜.
4. `/captions` : 말에 맞춘 자막, 스타일 3종(지금 말하는 단어 강조 / 말하는 대로 단어가 나타남 / 문장 전체 표시). 슬롯 [고를 스타일]. 또렷한 문구로 말하기.
5. `/glass-graph` : 숫자를 말하면 턱 아래 유리 패널에서 값까지 숫자가 올라가고 추세선이 그려짐. 슬롯 [항목과 숫자]. 구체적 숫자·퍼센트·변화량을 말하기.
6. `/freeze-frame` : 자기소개/새 포인트마다 플래시와 함께 정지, 말하는 사람만 원색이고 배경은 흑백, 스티커 외곽선+이름표. 슬롯 [이름표 내용]. "저는 [이름]이에요." "두 번째는요."처럼 분명히.
7. `/over-the-shoulder` : '전'/'후' 비교 시 숫자 카드 두 장이 등 뒤에 나타나고 카메라가 한 카드에서 다른 카드로 이동. 슬롯 [전 값], [후 값]. (❌ "예전보다 많이 늘었어요" ✅ "처음엔 [전 숫자]였는데, 지금은 [후 숫자]예요")
8. `/full-reel` : 슬롯 [영상 예: 오늘 찍은 클립]. 결과를 여러 효과를 이은 영상의 마지막 몽타주에 짧게 잘라 써도 됨.

### 여러 효과를 한 편으로
1. 넣을 효과를 고르고 효과마다 할 말을 한 줄씩 정리(예: `/tier-list`=도구 이름과 등급, `/glass-graph`=숫자 하나).
2. 효과마다 클립을 따로 촬영.
3. 클립 하나에 명령어 하나씩 전송.
4. 결과는 higgsfield.ai의 Assets에 저장 → 내려받아 평소 쓰는 편집 앱에서 순서대로 이어 붙임. 마지막 몽타주에 `/full-reel` 결과를 짧게 넣어도 됨.

## 핵심 팁 · 주의사항
- 대괄호 칸을 비우면 내가 원한 값이 안 들어감.
- 얼굴은 밝게, 그래픽 자리를 얼굴 주변에 남기기.
- 고칠 점은 한 번에 모아서 요청(재생성마다 크레딧 소모).
- 내가 찍었거나 허락받은 영상만 업로드.
- 클로드가 도구 호출 없이 말로만 답하면 `+` → Connectors에서 Higgsfield 켜짐 확인.
- `Authorization with the MCP server failed`가 뜨면 Customize → Connectors에서 Higgsfield 해제 후 재연결.

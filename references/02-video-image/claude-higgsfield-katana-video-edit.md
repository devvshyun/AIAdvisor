# 클로드에 원본 영상 올리고 10분 뒤 모션 그래픽 완성본 받는 법
- 원문: https://lazyowen.com/guides/claude-higgsfield-katana-video-edit
- 도구·주제: Claude + Higgsfield 카타나(Katana) 커넥터 · 프리셋 기반 영상 재편집
- 한 줄 요약: Claude에 Higgsfield 커넥터를 연결하고 `/katana` 프리셋(Personalized edits / Style transfer / Motion transfer)으로 내 원본 영상을 레퍼런스 편집 스타일(컷 순서·길이·음악 컷)로 다시 만든다. 약 20분, 영상 1개당 편집 약 10분. (2026-10-14 공개)

## 언제 쓰나
- 찍어 둔 원본 영상에 모션 그래픽까지 넣어 편집하고 싶은데 막막할 때
- 레퍼런스(프리셋)의 장면 순서·길이·음악에 맞춘 컷을 가져와 내 인물/제품 영상으로 다시 만들고 싶을 때

## 준비물 / 필요 도구
- claude.ai 웹 또는 Claude 데스크톱 앱 (API 키 불필요)
- Higgsfield 유료 구독 (오픈소스 아닌 웹 서비스)
  - 사이트: https://higgsfield.ai/
  - 카타나 페이지: https://higgsfield.ai/katana
  - 요금제: https://higgsfield.ai/pricing
  - 카타나 소개: https://higgsfield.ai/blog/higgsfield-katana
  - 클로드 연결 안내: https://higgsfield.ai/creator-hub/help-center/integrations/how-do-i-connect-higgsfield-to-ai-agent
  - MCP 크레딧 안내: https://higgsfield.ai/creator-hub/help-center/integrations/what-is-higgsfield-mcp
- 커넥터 MCP 서버 URL
```
https://mcp.higgsfield.ai/mcp
```
- 비용: 카타나 별도 이용료 없음, Higgsfield 요금제의 크레딧 사용. Claude에서 하는 생성은 요금제의 무료 생성·무제한이 적용되지 않아 매번 크레딧이 들며, 생성 전에 Claude가 정확한 비용을 먼저 보여 준다.
- 용어: 카타나 = Higgsfield가 Claude용으로 만든 편집 기능(타임라인 편집 앱이 아님. 프리셋·레퍼런스의 컷 순서·속도·편집을 따라 영상을 다시 만들고 필요한 장면은 직접 생성). 커넥터 = Claude에 다른 서비스를 붙이는 연결 설정(한 번 연결하면 새 대화마다 재설정 불필요). 프리셋 = 움직임·스타일·배치가 미리 정해진 편집 틀.

## 단계별 방법
### 프롬프트 뼈대 A. 연결 확인부터 첫 편집본까지 위임 (STEP 1 연결 후, claude.ai 새 대화 첫 메시지)
- 목적: 연결 확인 → 업로드 → 프리셋 추천 → 편집까지 맡기기
- 역할: 카타나로 내 원본 영상 편집을 맡는 편집 담당, 사용자는 편집 초보
- 슬롯: [내 스타일 = 원하는 편집 느낌 한 줄] (예: 자막·모션 그래픽 많은 정보 전달 스타일). 영상은 업로드 창에서 직접 선택
- 작업: Higgsfield 도구로 크레딧 잔액 조회(연결 확인) → 도구를 못 쓰면 설정 → 커넥터 → 커스텀 커넥터 추가 순서를 안내하고 멈춤 → 업로드 창 열기 → 카타나 프리셋 중 내 스타일에 맞는 3개 추천, 선택하면 그 프리셋으로 편집
- 제약: 생성 전 매번 크레딧 비용 표시 후 승인 대기, 채팅 첨부 대신 Higgsfield 업로드 창 사용, 한 번에 영상 하나
- 출력: 프리셋 이름, 쓴 크레딧, 완성본 미리보기, 남은 문제
- 검증: 잔액을 도구로 조회해 숫자로 답하는지, 완성본이 미리보기+다운로드 버튼으로 나오는지. 실패하면 실패 단계·원인·다음 조치 보고

### Quick Start
Claude 커넥터 주소 칸에 `https://mcp.higgsfield.ai/mcp` 를 붙여넣으면 커넥터 목록에 Higgsfield가 나타난다(위치·순서는 STEP 1).

### STEP 1. 클로드에 Higgsfield 커넥터 연결 (3분)
1. claude.ai 또는 데스크톱 앱에서 설정(Settings) → 커넥터(Connectors)
2. 커스텀 커넥터 추가(Add custom connector)
3. 이름에 `Higgsfield`, MCP 서버 URL에 `https://mcp.higgsfield.ai/mcp` 입력 후 계속
4. 연결(Connect) → Higgsfield 로그인 창에서 로그인·권한 허용(higgsfield.ai에 이미 로그인돼 있으면 자동 통과)
5. 새 대화에서 연결 확인
```
내 힉스필드 크레딧 잔액이 얼마야?
```
Claude가 Higgsfield 도구를 불러 잔액을 숫자로 알려 주면 성공.

### STEP 2. 원본 영상을 Higgsfield 업로드 창으로 올리기 (2분)
채팅에 바로 첨부한 파일은 Higgsfield로 넘어가지 않는다. 대화 안의 Higgsfield 업로드 창에서 고른 파일만 내 Higgsfield 계정에 올라간다.
```
원본 영상을 카타나로 편집하고 싶어. 힉스필드 업로드 창을 열어 줘.
```
업로드 창이 열리고 파일을 고르면 완료 확인이 나온다. Claude가 채팅 첨부를 요구하면 "내 파일용 힉스필드 업로드 창을 열어 줘"라고 다시 말한다. 영상 파일로 바로 이어지는 링크는 붙여도 되지만 인스타그램·틱톡 링크는 불가(파일로 업로드). 내가 찍었거나 사용 허락받은 영상만, 안에 든 음악·로고도 쓸 권리가 있어야 한다.

### STEP 3. /katana로 편집 스타일 고르기 (3분)
1. 프리셋 목록 열기
```
/katana
```
프리셋 3종: 퍼스널라이즈드 에디트(Personalized edits, 완성된 편집에 내 인물·제품 삽입) / 스타일 트랜스퍼(Style transfer, 레퍼런스 화면 느낌 입히기) / 모션 트랜스퍼(Motion transfer, 레퍼런스 움직임 옮기기). 목록에는 Higgsfield 제작 프리셋과 커뮤니티 프리셋이 섞여 있다.
2. 이름을 이미 알면 바로 호출
```
/katana/<프리셋 이름>
```
3. 같은 영상으로 다른 프리셋을 또 요청해 여러 스타일을 받을 수 있으나 매번 크레딧이 드니 하나씩 확인하며 늘린다.
4. 대안: 카타나 페이지(https://higgsfield.ai/katana)의 시작 폼에서 레퍼런스 동영상, 내 사진(캐릭터), 지침(선택)을 넣고 "Send & Generate in Claude"를 누르면 내용이 Claude 대화로 넘어간다.

### STEP 4. 편집 프롬프트 보내고 비용 확인 (2분)
프리셋에서 가져오는 것은 장면 순서, 장면별 길이, 음악에 맞춘 컷 위치 세 가지. 꼭 지킬/강조할 장면은 한 줄 덧붙인다.
```
방금 올린 영상을 힉스필드 카타나의 <프리셋 이름> 프리셋으로 편집해 줘. 생성하기 전에 크레딧 비용을 먼저 보여 주고 내 승인을 기다려 줘.
```
정확한 크레딧 비용 카드가 먼저 나오고, 금액을 보고 승인하면 편집이 시작된다. 쓸 크레딧 한도를 정하려면 "크레딧은 50 이상 쓰지 마"처럼 덧붙이되, 이는 대화 속 부탁일 뿐 자동으로 막히지 않으므로 비용 카드를 매번 직접 확인한다.

### STEP 5. 기다렸다가 편집본 확인하고 받기 (10분)
1. 영상 하나에 약 10분. 기다리는 동안 다른 일을 해도 되고, 같은 대화에서 상태를 묻는다.
```
다 됐어?
```
2. 완료되면 대화창에 미리보기와 다운로드 버튼이 달린 완성본이 나오며, higgsfield.ai의 Assets에도 저장된다.
3. 수정은 말로 요청(예: "두 번째 장면을 더 짧게 해 줘"). 바뀌는 장면만 재생성하며 새 생성에는 크레딧이 더 든다.
4. 편집 없이 화면 비율만 세로로 바꾸려면 카타나 대신 리프레임(reframe, 영상 확장)을 요청.
5. 결과가 안 보이면 1분쯤 뒤 higgsfield.ai의 Manage Account → Usage에서 작업이 돌았는지 확인. 일부 생성은 검수에서 거절될 수 있으니 그땐 다른 프리셋/영상으로 재요청.

## 핵심 팁 · 주의사항
- ❌ 영상 파일을 채팅 입력창에 끌어다 놓기(Higgsfield 도구가 못 읽음) → ✅ 업로드 창을 열어 달라 하고 거기서 파일 선택
- ❌ "멋지게 편집해 줘"만 보내기(스타일 미정인 채 크레딧 소모) → ✅ 프리셋 이름 + 꼭 지킬 것 하나(예: "첫 장면의 앱 화면은 바꾸지 말아 줘.")
- 한 대화에서 영상 하나씩 진행, 여러 영상을 한꺼번에 맡기지 않기
- 모든 생성에 크레딧이 들며 무제한 혜택이 적용되지 않음 → 비용 카드 직접 확인
- 저작권: 내가 찍었거나 허락받은 영상, 음악·로고 권리 확인

## 문제 해결
- Claude가 도구를 부르지 않고 말로만 답함: 새 대화를 열고 질문에 힉스필드를 명시, 대화별 커넥터 스위치에서 Higgsfield가 켜져 있는지 확인
- `Authorization with the MCP server failed`: 설정 → 커넥터 → Higgsfield에서 Disconnect 후 재연결
- Claude가 채팅 첨부를 요구: "내 파일용 힉스필드 업로드 창을 열어 줘"
- 결과 미표시/검수 거절: 위 STEP 5-5 참고

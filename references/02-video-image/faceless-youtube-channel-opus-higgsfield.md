# 월 1000만원 버는 유튜브 채널, 클로드 오퍼스로 만드는 5단계 (얼굴 없는 유튜브 채널)
- 도구·주제: Claude Opus 5.5 · Higgsfield MCP/CLI · 얼굴 없는 유튜브 채널 / 영상 제작 파이프라인 (2026-10-08 공개, STEP 5개, 약 14분 분량 글)
- 한 줄 요약: 리서치 → 대본 재구성(Opus 5.5) → 힉스필드 연결 → 설명 영상 제작 → 쇼츠 변환의 5단계 워크플로. 월 1000만원은 제목상의 문구이며 수익 보장이 아니다.

## 언제 쓰나
- 얼굴/목소리 노출 없이 설명형 영상 + 쇼츠 채널을 운영하고 싶을 때
- 힉스필드 MCP는 클로드가 힉스필드의 영상·이미지·음성 생성 도구를 직접 부르는 통로일 뿐, 유튜브 업로드를 대신해 주지는 않음

## 준비물 / 필요 도구
- Claude: 모델 목록에서 Opus 5.5를 고를 수 있는 플랜 — https://claude.ai / Opus 5.5 https://www.anthropic.com/claude-opus-5-5
- Higgsfield 유료 구독 필수. 클로드를 통한 생성마다 표준 요율로 크레딧 차감(구체 요금은 Higgsfield 요금표 확인)
  - MCP 안내 https://higgsfield.ai/mcp · MCP 서버 URL `https://mcp.higgsfield.ai/mcp`
  - 스킬 저장소(MIT) https://github.com/higgsfield-ai/skills (스타 1,200+) · 스킬 목록 https://higgsfield.ai/skills
  - 설명 영상 스킬 Editorial Motion Graphics https://higgsfield.ai/skills/editorial-motion-graphics
  - 연결 도움말 https://higgsfield.ai/creator-hub/help-center/integrations/how-do-i-connect-higgsfield-to-ai-agent
  - MCP 서버는 오픈소스가 아닌 웹 서비스
- 환경: 브라우저 claude.ai 또는 데스크톱 앱이면 됨. 터미널 Claude Code 경로는 Node.js(LTS, https://nodejs.org) 필요
- 유튜브 수익 조건 https://support.google.com/youtube/answer/72851?hl=ko / 정책 https://support.google.com/youtube/answer/1311392?hl=ko / AI 콘텐츠 공개 https://support.google.com/youtube/answer/14328491
- 용어: MCP=AI가 외부 서비스를 부르는 연결 규격, 스킬=특정 작업의 순서·규칙을 적은 설명서 묶음, CLI=터미널 명령으로 쓰는 프로그램, B롤=내레이션 뒤에 깔리는 보조 화면, 워크스페이스=힉스필드에서 크레딧·작업물을 묶는 공간

## 단계별 방법
**시작 전: 분야가 단가를 정한다**
- CPM(광고 1,000회 노출당 광고주 지불액) 예: 금융 설명 약 $18~50, AI·테크 설명 약 $10~25, 게임 약 $2. RPM(조회 1,000회당 채널 실수익)은 수익 분배 후라 CPM보다 낮음 → 그대로 내 수입이 아님. 수익 창출이 켜지면 YouTube 스튜디오 분석에서 내 RPM 확인
- 분야는 단가 높은 쪽(금융·AI/테크·비즈니스·건강)에서 꾸준히 따라갈 수 있는 것 하나. 형식은 뉴스 리액션/의견 말고 설명 영상(몇 달 지나도 검색돼 옛 영상·새 영상이 함께 수익)

**Claude Code용 시작 프롬프트 뼈대 (힉스필드 CLI 설치·로그인·크레딧 확인 위임)**
- 역할: 힉스필드 CLI 설치·연결 확인 담당. 맥락: 초보, CLI 미설치일 수 있음. 채울 곳: [채널 주제 한 줄]
- 작업: ① `node --version`(없으면 설치 방법만 알리고 중단) ② `higgsfield --version` 확인, 없을 때만 먼저 물은 뒤 `npm i -g @higgsfield/cli` ③ `higgsfield auth login`(브라우저 로그인 대기) → 현재 폴더에서 `npx skills add higgsfield-ai/skills -a claude-code -y`(선택 화면 없이 종료) → `higgsfield account status` ④ 연결된 것과 첫 영상 만들 때 다음 할 일을 초보자 눈높이로 설명
- 제약: 이미지·영상·음성 생성 금지(크레딧 소모), sudo·전역 설치·설정 수정 전 질문, 토큰·비밀번호 출력 금지, 기존 파일 덮어쓰기 금지
- 검증: `higgsfield --version`이 버전 숫자, `higgsfield account status`가 이메일·요금제·크레딧을 보여야 함. 실패 시 완료 보고 금지

**STEP 1. 리서치: 이미 터진 영상 5개 (약 30분)**
1. 유튜브에서 내 분야의 설명형 검색어(예: "AI 에이전트 원리") 검색 → 필터에서 업로드 날짜 "이번 달"
2. 조회수 500,000회 이상만 남기고, 사람 얼굴이 나오는 영상은 제외(애니메이션·화면 녹화·스톡+내레이션만 통과)
3. 통과한 5~10개를 재생목록 하나에 저장 → 향후 2주치 주제
4. (선택) 웹 검색이 켜진 클로드에 위임. 프롬프트 뼈대: [내 분야]에서 이번 달 올라온 조회수 50만+ 얼굴 없는 설명 영상을 제목·채널·조회수·링크 표로 5~10개 정리, 조회수 확인 못한 영상은 제외. 결과는 직접 링크를 열어 조회수·얼굴 여부 확인
5. 고른 영상의 설명란 → 스크립트 버튼에서 전체 대본을 복사해 둠(다음 단계에서 "주제 지도"로만 사용)
- ❌ 100만 조회라도 얼굴 나오는 토크 영상 포함 → ✅ 얼굴 없이 터진 영상만 (내 형식도 클릭 받는다는 증거)

**STEP 2. Opus 5.5로 대본 업그레이드 (약 20분)**
1. claude.ai에서 모델을 Opus 5.5로 선택, 복사한 대본을 프롬프트 뒤에 붙임
2. 프롬프트 뼈대: 이 주제로 조회수 [실제 조회수] 영상의 대본을 첨부. 같은 주제로 최신 정보·더 강한 훅·더 탄탄한 이야기의 8분 대본. 먼저 주제를 조사해 영상 이후 바뀐 내용 반영. 일반 시청자용 한국어 구어체. 구성 순서: 첫 20초 안의 훅 → 무엇을 알게 되는지 약속 → 이야기로 풀어가는 설명 → 다음 영상으로 이어지는 마지막 한 줄. 원문 문장은 그대로 쓰지 말고 새 문장으로
3. 영어 채널이면 같은 구조의 영어 프롬프트 사용(영상 조회수 자리 숫자만 교체). 같은 주제면 최신 영상이 클릭을 받으므로 몇 달 전 터진 영상도 새 버전으로 이길 수 있음
4. 영상화 전 점검: 처음부터 끝까지 직접 읽고 어색한 문장 수정 / 금융·건강은 숫자·주장을 공식 출처와 재확인(틀린 숫자 하나가 신뢰를 무너뜨림) / 첫 20초에 훅이 있는지
- ❌ "이 대본을 한국어로 번역해 읽어줘" → 남의 대본 재낭독은 수익 창출 심사에서 재사용 콘텐츠로 거절됨. ✅ 원본은 "이 주제가 먹힌다"는 증거로만 쓰고 조사·구성·문장은 새로 받기

**STEP 3. 힉스필드 MCP 연결 (약 5분)**
- 웹/데스크톱 (claude.ai):
  1. Settings → Connectors (왼쪽 아래 프로필 → 설정 → 사용자 지정 아래 커넥터)
  2. 오른쪽 위 Add → Add custom connector
  3. 이름 `Higgsfield`, MCP 서버 URL `https://mcp.higgsfield.ai/mcp` → Continue → 안내 따라 진행 → 힉스필드 창에서 로그인·승인
  4. 활성 커넥터 목록에 Higgsfield가 보이면 성공
  5. 새 대화에서 "내 힉스필드 크레딧 잔액이 얼마야?"라고 물어 도구를 불러 답하면 연결됨. 도구 없이 답하면 커넥터를 끊었다가 재연결
- Claude Code (CLI): 작업할 폴더로 이동 후
```bash
node --version        # v로 시작하는 버전이면 OK, 없으면 nodejs.org LTS 설치 후 터미널 재실행
higgsfield --version  # 이미 설치돼 있으면 아래 npm 설치는 건너뜀
npm i -g @higgsfield/cli
higgsfield auth login
npx skills add higgsfield-ai/skills -a claude-code -y   # 마지막에 Done! 이 보이면 성공
higgsfield --version
higgsfield account status   # 이메일·요금제·남은 크레딧
```
  - `No workspace selected`: `higgsfield auth login`을 했는지 확인 → 그래도 같으면
```bash
higgsfield workspace list
higgsfield workspace set <워크스페이스 ID>
```
- ❌ 연결하자마자 "영상 만들어줘" → 힉스필드에는 대화별 크레딧 상한 기능이 없어 생성이 계속될 수 있음. ✅ 대화 첫 줄에 "크레딧은 <숫자> 이하로만 쓰고, 생성 전에 항상 내 승인"을 명시

**STEP 4. 카메라 없이 영상 만들기 (약 1시간)**
1. 브라우저 클로드는 STEP 3 커넥터만 있으면 Editorial Motion Graphics 스킬을 별도 설치 없이 사용. Claude Code는 STEP 3에서 추가한 공식 스킬 사용
2. 프롬프트 뼈대: 아래 대본으로 힉스필드 Editorial Motion Graphics 스킬을 써서 얼굴 없는 설명 영상 제작. 내레이션 목소리는 전체 하나로 유지, 화면 자막, 섹션마다 맞는 애니메이션 장면과 B롤 그래픽. 모든 영상에서 같은 화풍·같은 내레이터로 채널이 한 프로그램처럼 보이게. 생성 전 섹션별 예상 크레딧 먼저 공지, 크레딧은 [숫자] 이하, 한 섹션씩 만들며 매번 승인. 마지막에 대본 붙임
3. 캐릭터가 나오는 채널이면 힉스필드 Soul 캐릭터를 하나 만들어 매 영상에 동일 사용
4. 완성 확인: 내레이터 목소리가 지난 영상과 같은지, 화면 숫자가 대본과 같은지. 마음에 안 들면 그 섹션만 같은 프롬프트로 재생성. 생성이 안 보이면 60초쯤 기다린 뒤 힉스필드 계정 사용 내역에서 작업이 돌았는지 확인
5. 업로드: 제목은 실제 검색어에 가깝게, 썸네일 문구 4단어 이하, 설명 첫 줄에 영상이 답하는 질문. 실제 사람 같은 AI 음성/실제처럼 보이는 장면이 있으면 업로드 세부정보의 AI 사용 공개 항목에서 공개 선택(헷갈리면 공개)

**STEP 5. 숏폼으로 불리기 (약 30분)**
- 프롬프트 뼈대: 방금 영상 대본에서 30~60초짜리 가장 강한 장면 3~5개 선정, 장면마다 훅 한 줄 + 놀라운 사실 하나. 힉스필드로 세로 9:16 제작, 모든 쇼츠의 마지막 줄은 "전체 설명은 채널에 있습니다"(긴 영상으로 유도), 생성 전 예상 크레딧 공지
- 이미 올린 긴 영상은 힉스필드 Personal Clipper로 클립 자르기 가능
- 쇼츠/릴스/틱톡에 업로드. 쇼츠는 단가 높은 긴 영상으로 사람을 데려오는 무료 광고 역할
- 유튜브 파트너 프로그램(수익 창출) 조건 둘 중 하나: 구독자 1,000명 + 12개월 공개 영상 시청 4,000시간 / 구독자 1,000명 + 90일 쇼츠 조회 1,000만. 쇼츠 피드 시청 시간은 4,000시간에 불포함 → 쇼츠는 조회수 길, 시청 시간은 긴 영상으로

**매주 루틴 (주 5~6일 발행)**
- 월: STEP 1 리서치로 주제 5~6개 / 화: STEP 2 대본 + 전부 직접 검수 / 수·목: STEP 4 영상 생성, 목소리·숫자 확인 / 금: STEP 5 쇼츠 + YouTube 스튜디오 업로드 예약
- 사람이 하는 일은 대본 검수와 완성본 확인 두 가지. 대본은 한 편도 빼지 않고 읽기
- 6개월째에는 그달 영상만이 아니라 누적 영상이 함께 수익. 첫 영상은 구독자 0명이어도 업로드(파이프라인 익히기용)

## 핵심 팁 · 주의사항
- 크레딧: 힉스필드는 대화별 상한이 없으므로 첫 줄에 상한과 섹션별 승인 조건을 명시. 연결 직후엔 잔액 조회만
- 남의 대본 번역/재낭독은 재사용 콘텐츠로 수익 거절 가능
- 분야별 CPM 수치는 광고주 지불액이지 실제 수익이 아님 (RPM은 더 낮음)
- MCP는 업로드를 하지 않으므로 유튜브 업로드는 직접
- 금융·건강 수치는 공식 출처 확인, AI 음성/장면은 AI 사용 공개 체크
- 목소리·화풍·내레이터를 모든 영상에서 통일

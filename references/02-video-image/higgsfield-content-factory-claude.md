# 힉스필드 콘텐츠 팩토리 숏폼 공장
- 원문: https://lazyowen.com/guides/higgsfield-content-factory-claude
- 도구·주제: Higgsfield Content Factory + Claude 커넥터 · 숏폼 설명 영상 / 제품 홍보 (STEP 5개, 약 16분)
- 한 줄 요약: Higgsfield MCP를 Claude에 연결하고 Content Factory에서 스타일을 골라 30초 9:16 애니메이션 설명 영상을 만든 뒤, 제품 소개와 판매 링크 연결까지 잇는다.

## 언제 쓰나
- 얼굴을 드러내거나 제작비를 쓰지 않고 시리즈형 숏폼 설명 영상을 꾸준히 올리고 싶을 때
- 앞 25초는 주제 설명, 마지막 5초에 제품을 소개하는 부드러운 홍보 영상이 필요할 때
- Content Factory는 유행 영상 스타일을 고르고 주제를 넣으면 올릴 수 있는 숏폼을 한 편씩 만드는 힉스필드 기능(편집 앱이 아니라 클로드 대화창 안에서 동작). 대본·그림·나레이션·음악·자막을 한 번에 생성

## 준비물 / 필요 도구
- Higgsfield Content Factory: https://higgsfield.ai/content-factory (예시 스타일마다 원본 영상의 조회수·좋아요 표기)
- MCP 안내: https://higgsfield.ai/mcp · 커넥터 URL `https://mcp.higgsfield.ai/mcp`
- 요금: https://higgsfield.ai/pricing
- Claude 커스텀 커넥터 도움말: https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp
- TikTok Shop 제품 추가: https://support.tiktok.com/en/business-and-creator/tiktok-shop-for-creators/adding-products-to-videos
- Instagram 제품 태그: https://help.instagram.com/2022466637835789
- 환경: 브라우저 + Claude 계정(웹/데스크톱) + Higgsfield 계정. 설치·API 키 불필요. 오픈소스 아님(웹 서비스, 제작사 Higgsfield, Inc.)
- 비용: Claude 커스텀 커넥터는 무료 플랜도 1개까지. 영상마다 힉스필드 크레딧이 소모되므로 크레딧 있는 요금제 필요

## 단계별 방법
**빠른 시작 프롬프트 뼈대 (비용 확인부터 30초 한 편 완성까지 위임)** — STEP 1 연결 후 새 대화에 붙여넣기
- 역할: 힉스필드 콘텐츠 팩토리로 숏폼 애니메이션을 만드는 제작 담당. 맥락: 영상 편집 초보, 커넥터 방금 연결, 영상마다 크레딧 소모
- 채울 곳: [내 주제 — 예: 우리가 잠들 때 뇌 속에서 실제로 일어나는 일]
- 작업: ① Higgsfield 도구 사용 가능 여부를 도구 목록으로 확인, 없으면 연결 방법만 안내하고 중단 ② 고른 레퍼런스 스타일이 없으면 후보를 먼저 보여 주고 사용자가 고르게 한 뒤, 30초·9:16·1편 구성안(첫 장면/중간 전개/마무리) 제시 ③ 한국어 나레이션·효과음·읽기 쉬운 한국어 자막 조건으로 생성 전에 크레딧 비용을 알리고 승인 대기 ④ 승인 후 생성, 결과 링크와 활용법 안내
- 제약: 비용 안내 전 생성 금지, 승인 없이 두 편 이상 금지, 실존 인물 얼굴·이름·타사 로고 금지, 한국어 나레이션 불가 시 생성 전에 고지
- 검증: Higgsfield 도구가 목록에 있고, 생성 전 비용을 말했고, 결과가 30초·9:16 한 편인지 확인. 하나라도 실패하면 완료 보고 금지

**STEP 1. 클로드에 힉스필드 연결 (3분)**
1. 가장 쉬운 길: 힉스필드가 만든 바로가기로 이름·주소가 채워진 추가 창 열기
```
https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=Higgsfield&connectorUrl=https%3A%2F%2Fmcp.higgsfield.ai%2Fmcp
```
   (한국어 화면의 '외부 링크에서 제안되었습니다' 경고는 바로가기로 열 때 나오는 안내. '연결 대상'이 mcp.higgsfield.ai 인지 확인 후 계속)
2. 직접 하려면 Customize > Connectors > `+ Add` > `Add custom connector`, 이름 `Higgsfield`, 서버 주소 `https://mcp.higgsfield.ai/mcp`
3. `Add` 또는 `Connect` → 힉스필드 로그인·연결 허용
4. 새 대화 왼쪽 아래 `+` → `Connectors`에서 Higgsfield 스위치가 켜져 있는지 확인. 성공하면 목록에 보이고 켜고 끌 수 있음
- 무료 플랜인데 다른 커스텀 커넥터가 이미 있으면 막힘 → 안 쓰는 것 하나 삭제 후 재추가
- 팀·기업 플랜은 조직 관리자가 먼저 등록해야 함(위 주소를 전달)

**STEP 2. 콘텐츠 팩토리에서 스타일 고르기 (2분)** — 스타일을 먼저 골라야 엉뚱한 화풍을 피함
1. https://higgsfield.ai/content-factory 열기
2. 예시 영상 중 마음에 드는 것에서 `Use as reference` (내 이미지로 분위기를 잡으려면 `Add reference`)
3. `Make a video about…` 칸에 주제를 한 문장으로
4. 길이 `30 sec`, 편수 `1 episode`
5. `Generate in Claude` → 준비된 요청을 들고 클로드로 이동 (`Connect Higgsfield MCP to generate`가 보이면 STEP 1부터)
- ❌ `뇌` (단어 하나) → ✅ `우리가 잠들 때 뇌 속에서 실제로 일어나는 일` (읽자마자 장면이 떠오르는 질문 문장)

**STEP 3. 클로드에게 완성 조건 보내기 (3분)** — 넘어온 요청 아래에 덧붙임
- 프롬프트 뼈대: 콘텐츠 팩토리로 30초 9:16 애니메이션 설명 영상 한 편. 채울 곳: [STEP 2 주제 문장]. 고른 레퍼런스 스타일 따르기, 첫 장면은 강하게 시작해 점점 고조되다가 시원하게 마무리. 한국어 나레이션·효과음·읽기 쉬운 한국어 자막, 한국어 나레이션이 불가하면 생성 전에 알림. 생성 전에 짧은 구성안과 크레딧 비용부터 공지
- 클로드가 구성안·비용을 알리고 진행 여부를 물음. 한국어 나레이션 불가이면 "영어 나레이션 + 한국어 자막"으로 변경 요청
- 빠진 정보를 묻거나 도구 실행 허락 창이 뜨면 응답/허용. 승인하면 대본·그림·나레이션·음악·자막을 한 번에 생성
- ❌ "잠에 대한 영상 여러 개 만들어줘" → ✅ "30초, 9:16, 한 편만 만들고 생성 전에 크레딧 비용부터 알려 주세요". 처음엔 가장 작은 단위(30초 한 편)로

**STEP 4. 내 제품을 알리는 영상으로 바꾸기 (5분)**
- 주제는 제품 자체가 아니라 제품이 해결하는 문제. 궁금한 주제를 풀어 주는 영상이 광고보다 거부감이 적음
- 프롬프트 뼈대: STEP 3과 같은 틀에 [주제: 문제 상황 — 예: 밤에 자꾸 깨는 사람의 몸에서 일어나는 일]을 넣고, 앞 25초는 주제를 쉽게 풀이, 마지막 5초에만 [제품명]이 문제를 어떻게 돕는지 한 문장 소개. 한국어 나레이션·효과음·자막, 한국어 나레이션 불가 시 사전 고지, 생성 전 크레딧 비용 공지
- 같은 틀로 얼굴 없는 채널 연재나 어려운 개념 설명 영상도 가능
- ❌ "우리 수면 안대 광고 영상 만들어줘" → ✅ "밤에 자꾸 깨는 이유를 25초 동안 풀고, 마지막 5초에만 수면 안대를 소개해 줘"
- 제품 효과는 실제로 말할 수 있는 것만(예: "병이 낫는다" 같은 효능 문구 금지), 결과물 자막도 재점검. 실존 인물 얼굴·타사 로고가 나오면 업로드하지 말고 해당 장면 제거 재요청. 업로드 플랫폼의 AI 생성 콘텐츠 표시 설정이 있으면 켜기

**STEP 5. 올린 영상에 내 제품 연결 (3분)** — 힉스필드는 영상까지만 만들고 연결은 업로드 플랫폼에서
1. 완성본을 저장해 휴대폰으로 옮김
2. 틱톡샵 판매자/제휴 크리에이터 계정이면 업로드 화면에서 상품 추가(서비스가 열린 나라에서만 가능, 메뉴가 없으면 4번으로)
3. 인스타그램 쇼핑 가능 계정이면 게시 화면에서 제품 태그
4. 둘 다 안 되면 프로필 링크에 판매 페이지를 걸고, 마지막 5초 나레이션에 "프로필 링크에서 볼 수 있어요" 한 문장을 넣어 달라고 클로드에 요청
5. 성공하면 올린 영상에 상품 링크/제품 태그가 보이고 누르면 내 판매 페이지로 이동

**결과 점검 (업로드 전)** — 걸리면 그 부분만 한 문장으로 수정 요청
| 볼 곳 | 괜찮은 상태 | 걸리면 이렇게 |
|---|---|---|
| 첫 장면 | 처음 2초 안에 주제가 보임 | "첫 장면을 더 강하게 바꿔 주세요" |
| 자막 | 휴대폰 화면에서 한 번에 읽힘 | "자막을 더 크고 짧게 나눠 주세요" |
| 나레이션 | 자막과 같은 말 | "나레이션과 자막을 맞춰 주세요" |
| 길이·비율 | 30초 안팎, 세로 9:16 | "30초 9:16으로 다시 맞춰 주세요" |
- 괜찮은 영상이 나오면 같은 레퍼런스 스타일·같은 프롬프트 틀에 주제만 바꿔 다음 편 제작 → 시리즈 일관성

## 핵심 팁 · 주의사항
- 수정 요청에도 크레딧이 들 수 있음 → 고칠 때마다 비용을 먼저 알려 달라고 덧붙이기
- 한국어 나레이션이 안 될 수 있음 → 영어 나레이션 + 한국어 자막으로 대체
- 효능 표현 금지, 실존 인물 얼굴/타사 로고 제거, 플랫폼 AI 표시 켜기
- 무료 플랜 커스텀 커넥터 1개 제한, 팀/기업 플랜은 관리자 선등록
- 틱톡샵은 지원 국가 한정

## 바로 쓰는 체크리스트
- [ ] Higgsfield 커넥터 연결, 대화에서 스위치 ON 확인
- [ ] Content Factory에서 레퍼런스 선택, 질문형 주제, 30 sec / 1 episode
- [ ] 완성 조건(30초·9:16·한국어 나레이션·자막) + 비용 먼저 요청
- [ ] 제품은 마지막 5초에만 소개, 과장 효능 표현 제거
- [ ] 폰에 저장 후 TikTok/Instagram에서 제품 연결(또는 프로필 링크)
- [ ] 업로드 전 4가지 점검(첫 장면·자막·나레이션·길이/비율)

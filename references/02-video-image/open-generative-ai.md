# 유료 영상 AI 대신 쓰는 무료 스튜디오 입문 가이드 (Open Generative AI)
- 원문: https://lazyowen.com/guides/open-generative-ai
- 도구·주제: Open Generative AI · 영상·이미지 생성 (2026-08-11 공개, STEP 7개, 약 31분)
- 한 줄 요약: 오픈소스(MIT) 앱 하나로 이미지·영상 모델 200여 개를 한 화면에서 쓰고, muapi-cli와 스킬로 Claude Code/Codex 자동화까지 하는 입문.

## 언제 쓰나
- 영상 AI마다 따로 결제하지 않고 무료 계정/로컬 모델로 이미지→영상, 시네마 샷, 립싱크를 만들고 싶을 때
- 같은 생성 작업을 반복해서 명령줄/AI 코딩 도구로 자동화하고 싶을 때

## 준비물 / 필요 도구
- 앱: https://muapi.ai/open-generative-ai (웹 버전 가능, 로컬 실행은 설치본에만 있음)
- 저장소: https://github.com/Anil-matcha/Open-Generative-AI · 릴리스 https://github.com/Anil-matcha/Open-Generative-AI/releases
- 명령 실행 도구 muapi-cli: https://www.npmjs.com/package/muapi-cli
- AI 코딩 도구용 스킬 묶음: https://github.com/SamurAIGPT/Generative-Media-Skills
- 로컬 영상 생성 서버: https://github.com/deepbeepmeep/Wan2GP
- Node.js LTS: https://nodejs.org/ (자동화 시)
- 비용: 앱은 MIT 오픈소스 무료. 클라우드 모델은 무료 계정으로 시작하되 무거운 모델을 많이 돌리면 크레딧 필요할 수 있음. 로컬은 크레딧·계정 키 불필요하지만 하드웨어 필요

## 단계별 방법
**Quick Start**
1. 릴리스 페이지에서 내 OS용 설치본 다운로드 → 설치 → 앱 실행(경고는 STEP 2)
2. 무료 계정 로그인 → Image Studio에서 문장 입력 후 생성
3. 설치가 귀찮으면 웹(muapi.ai/open-generative-ai)에서 같은 스튜디오 사용
4. 자동화 계획이 있으면 미리:
```bash
npm install -g muapi-cli
muapi auth configure
```
   (설치 로그 후 키 입력 안내 → 입력하면 저장 메시지)

**설치~검증 위임 프롬프트 뼈대 (Claude Code)**
- 역할: Open Generative AI 설치·생성 연동 검증 담당 환경 설정자
- 채울 곳: [내 컴퓨터 상황 한 줄], [OS·셸], [기술 스택], [목표 한 줄 — 예: 무료로 짧은 영상 하나 뽑기]
- 작업: ① 설치 여부 확인(앱 목록/시작 메뉴, 자동화 시 `node --version`·`npm --version`) ② 미설치면 공식 릴리스에서만 설치 + OS별 첫 실행 경고 해제 안내 ③ 무료 계정 로그인, 자동화 시에만 `npm install -g muapi-cli` 후 `muapi auth configure` ④ Image Studio 이미지 1장, Video Studio 짧은 영상 1개를 실제 생성해 확인 ⑤ 앱 개요·탭별 역할·사용 순서를 쉬운 말로 설명
- 제약: 비밀번호·API 키 출력/저장 금지, 공식 저장소·사이트 외 링크 설치 금지, 기존 파일·설정 삭제 금지
- 출력/검증: 실행 명령, 앱·Node·npm 버전, 로그인 상태, 결과물 경로, 남은 오류. 앱이 경고 없이 열리고 이미지·영상이 생성돼야 하며, 자동화 시 `muapi image models`가 목록을 출력해야 함. 하나라도 실패하면 완료 보고 금지

**STEP 1. 설치본 내려받기 (2분)** — 최신 릴리스에서 선택
| 내 컴퓨터 | 받을 파일 |
|---|---|
| 맥 (M1·M2·M3·M4) | 이름에 `arm64`가 붙은 `.dmg` |
| 맥 (인텔) | `arm64`가 없는 `.dmg` |
| 윈도우 | `Setup`이 붙은 `.exe` |
| 우분투·리눅스 | `.deb` 또는 `.AppImage` |
- 맥 칩 확인: 왼쪽 위 사과 메뉴 → "이 Mac에 관하여" → 칩 이름에 M이 있으면 arm64

**STEP 2. 첫 실행 경고 넘기기 (3분)** — 개발자 서명이 없어 뜨는 안내, 한 번만 허용하면 다음부터 안 나옴
- 맥: 시스템 설정 → 개인정보 보호 및 보안 → 아래로 내려 차단된 앱 안내에서 "확인 없이 열기". 터미널이 더 빠름:
```bash
xattr -cr "/Applications/Open Generative AI.app"
```
  (성공하면 출력 없음)
- 윈도우: 파란 경고창에서 "추가 정보" → "실행"
- 리눅스: `.AppImage`가 안 열리면 `.deb` 설치 (또는 `sudo apt install libfuse2`)
- 앱이 열리면 무료 계정 로그인(로그인해야 클라우드 모델 목록이 열림)

**STEP 3. 탭 구조 익히기 (3분)** — 탭이 곧 모델 묶음. 탭을 잘못 고르면 모델이 안 보임
- Image Studio: 글로 이미지 생성 / 가진 이미지 수정
- Video Studio: 글로 영상 생성 / 이미지 한 장을 움직임
- Cinema Studio: 카메라 값을 직접 정해 영화 같은 장면
- Lip Sync Studio: 얼굴 사진/영상에 목소리를 붙임
- 이미지·영상을 올리면 모델 목록이 자동으로 바뀜(안 올리면 텍스트→생성 모델, 참고 이미지 올리면 수정/움직임 모델)

**STEP 4. 첫 이미지와 첫 영상 (5분)**
1. Image Studio → 모델 아무거나 선택 → 예시 프롬프트를 넣고 생성: "늦은 오후 창가에 앉아 노트북을 보는 사람, 따뜻한 햇빛, 사진처럼 사실적으로" → 결과는 기록 영역에 남고, 다운로드 버튼으로 원본 화질 저장
2. Video Studio → 방금 이미지를 시작 장면으로 올림 → 예시: "카메라가 아주 천천히 뒤로 물러나며 창밖 풍경까지 보여준다" → 같은 기록 영역에 저장. 첫 생성은 대기열로 오래 걸릴 수 있음
- 프롬프트는 짧게보다 장면을 눈에 보이듯 적는 편이 좋음

**STEP 5. 시네마 스튜디오로 화면 느낌 잡기 (5분)** — "영화처럼" 대신 카메라 값을 지정
- 카메라·렌즈·초점 거리·조리개를 고르면 프롬프트에 촬영 용어로 자동 추가됨
- 초점 거리 8mm~85mm: 작을수록 넓게, 클수록 대상만 크게
- 조리개: f/1.4 배경 흐림 / f/4 무난 / f/11 앞뒤 모두 선명
- 추천: 인물 감성은 35mm + f/1.4, 제품·풍경은 24mm + f/11
- 예시 장면: "빗속 골목을 걸어가는 사람의 뒷모습, 젖은 바닥에 비친 간판 불빛" → 값만 바꿔 두세 번 돌리면 차이 체감

**STEP 6. 클로드 코드·코덱스에 연결해 자동화 (10분)**
```bash
npm install -g muapi-cli
muapi auth configure
npx skills add SamurAIGPT/Generative-Media-Skills --all
muapi image models     # 모델 이름이 줄줄이 나오면 성공, 비면 키 저장 단계로 복귀
```
- 스킬 설치 후 추가된 스킬 목록이 출력됨
- 프롬프트 뼈대 (Claude Code / Codex): 설치된 생성 미디어 스킬로 [목표 한 줄 — 예: 신제품 이미지 5장 + 15초 영상 1개], [분위기]. 진행: 먼저 쓸 모델과 예상 단계를 짧게 제시 → 이미지를 먼저 만들고 가장 나은 한 장을 영상으로 → 결과를 [저장 폴더, 예: ./outputs]에 다운로드 → 마지막에 만든 파일 목록과 실패 단계 보고
- 성공 기준: 지정 폴더에 이미지·영상 파일이 실제 저장돼야 함(없으면 미완료)

**STEP 7. 무료로 쓰는 범위 확인 (3분)**
- 앱은 MIT 오픈소스(소스 전부 공개). 클라우드 모델은 무료 계정 시작, 무거운 모델은 크레딧 가능
- 크레딧을 쓰기 싫으면 설치본의 로컬 실행: ① 설정의 로컬 모델 항목에서 실행 엔진 1회 설치 ② 모델 하나 다운로드 ③ Image Studio에서 로컬 표시 켜고 생성 (계정 키 불필요)
- 영상 모델을 내 장비로 돌리려면 그래픽카드가 있는 PC가 필요. 메모리 8GB 맥이면 가장 가벼운 모델부터

## 핵심 팁 · 주의사항
- 경고를 바이러스로 오해해 파일을 지우면 같은 자리에서 계속 막힘 → 경고 해제 방법 사용
- 모델이 안 보이는 문제의 절반은 탭을 잘못 고른 것
- 순서 이유: 첫 실행 경고 → 탭 구조 → 기본 결과 확인 → 카메라 값 → 자동화(화면에서 한 번도 안 만든 사람이 명령으로 만들면 이상한 결과의 원인을 못 찾음)
- API 키·비밀번호는 출력/저장 금지, 설치본은 공식 저장소·사이트에서만
- 용어: 스킬 = AI 코딩 도구에 특정 작업 절차를 알려 주는 설명서 묶음

## 문제 해결
| 증상 | 원인 | 해결 |
|---|---|---|
| 맥에서 앱이 안 열림 | 서명 없는 설치본 차단 | 시스템 설정에서 확인 없이 열기 또는 `xattr -cr` 한 번 |
| 윈도우 파란 경고창 | 코드 서명 없는 설치 파일 | 추가 정보 → 실행 |
| 리눅스 AppImage 실행 실패 | 시스템 구성 요소 부족 | `.deb` 사용 또는 `sudo apt install libfuse2` |
| 원하는 모델이 목록에 없음 | 탭/입력 방식이 다름 | 이미지 생성/편집 구분 확인, 참고 이미지 업로드 여부 변경 |
| 생성 버튼 무반응 | 로그인 또는 키 미설정 | 무료 계정으로 재로그인 |
| `command not found: npm` | Node.js 미설치 | nodejs.org LTS 설치 후 터미널 재시작 |
| 로컬 모델이 너무 느림 | 메모리 부족으로 CPU 실행 | 더 가벼운 모델 또는 클라우드 모델 |

# 모션 그래픽 한 편을 10분 만에 만드는 레퍼런스 번역법
- 도구·주제: Claude + Google Flow(Omni Flash) + ffmpeg · 레퍼런스 영상 → 생성 프롬프트 → 모션 그래픽
- 한 줄 요약: 따라 하고 싶은 모션 그래픽을 프레임 사진으로 잘라 Claude에게 읽혀 생성 프롬프트로 번역시키고, 그 프롬프트를 Google Flow(Omni Flash)에 넣어 클립으로 받는다. (2026-09-12 공개, STEP 6개)

## 언제 쓰나
- 마음에 드는 모션 그래픽/광고 컷을 내 제품용으로 비슷하게 재생성하고 싶을 때
- 촬영 용어를 몰라도 장면을 영상 모델용 프롬프트로 바꾸고 싶을 때

## 준비물 / 필요 도구
- Google Flow (구글 로그인, 설치 불필요): https://flow.google.com/
  - 영상 만들기 안내: https://support.google.com/flow/answer/16353334
  - 모델별 지원 기능: https://support.google.com/flow/answer/16352836
  - 크레딧·요금제: https://support.google.com/flow/answer/16526234
  - 프롬프트 가이드: https://deepmind.google/models/gemini-omni/prompt-guide/
  - 모델 소개: https://deepmind.google/models/gemini-omni/
- Claude 웹 채팅 (사진 업로드: 채팅당 파일 20개, 파일당 500MB, JPEG·PNG·GIF·WebP): https://support.claude.com/en/articles/8241126-upload-files-to-claude
- ffmpeg: https://ffmpeg.org/ (터미널 대체: Ezgif https://ezgif.com/video-to-jpg)
- 참고 저장소: https://github.com/google-gemini/cookbook
- 사진을 읽을 수 있는 다른 AI 도구도 같은 프롬프트로 가능(핵심은 5항목 구조)
- 용어: 프롬프트 = AI에게 주는 글 지시문, 프레임 = 영상을 이루는 사진 한 장(1초에 보통 24~30장), 크레딧 = 생성 시 차감되는 이용권, 업스케일 = 다시 생성하지 않고 해상도만 키우는 기능

## 단계별 방법
### 프롬프트 뼈대 A. 환경 준비·검증 위임용 (선택, Claude에 붙여넣기)
- 목적: ffmpeg 유무, Flow 로그인·크레딧 확인 방법, 프레임 추출 검증까지 맡기기
- 역할: 모션 그래픽 생성 환경 준비·연결 검증 담당
- 슬롯: [운영체제·셸], [내가 쓰는 AI 도구], [목표 한 줄]
- 작업 4단계: ① `ffmpeg -version` 실행·보고, flow.google.com 로그인·남은 크레딧 확인법 안내(이미 있으면 재설치 말고 버전만) ② 없으면 macOS는 `brew install ffmpeg`, 윈도우는 공식 배포 페이지 안내, 터미널 거부 시 브라우저만으로 프레임 추출 안내 ③ 짧은 샘플로 `ffmpeg -i <영상 파일> -vf fps=1 frames/frame_%02d.jpg` 실행 후 사진 개수·크기 보고 ④ Claude와 Flow의 역할·순서를 5줄 이내로 설명
- 제약: 비밀번호·키 출력 금지, 임의 sudo 금지, 기존 파일 덮어쓰기 금지(새 폴더에만 결과)
- 출력: 실행 명령, 버전, 사진 경로, 남은 오류
- 검증: `ffmpeg -version`이 버전 숫자를 돌려주고 frames 폴더에 사진 1장 이상. 실패 시 완료 보고 금지

### Quick Start. Flow를 영상 모델로 설정 (설치 없음)
```
1. flow.google.com 접속 후 구글 계정으로 로그인
2. 새 프로젝트 만들기
3. 프롬프트 상자에서 모델 이름을 클릭
4. Video 선택 → Omni Flash 선택
5. 길이 4s, 출력 수 1로 설정
```
모델 이름 자리에 Omni Flash가 보이면 준비 끝. 시험 삼아 아래 프롬프트를 그대로 넣고 생성하면 몇 분 뒤 4초 클립이 나온다.
```
익스트림 매크로로 천천히 밀고 들어가는 카메라. 고급 광고 사진 느낌의 실사 영상, 얕은 심도. 왼쪽 위에서 부드러운 빛이 들어오고 배경은 따뜻한 크림색. 초콜릿 바가 반으로 갈라지며 부스러기가 밖으로 퍼졌다가 가라앉는다. 대사 없음.
```

### STEP 1. 따라 할 레퍼런스 고르기 (2분)
인스타·틱톡·유튜브에서 모션 그래픽 한 편을 저장한다. 기준:
- 10초 안쪽 (길면 장면이 여러 개라 한 번에 못 만듦)
- 카메라가 크게 움직이지 않는 한 컷짜리가 성공률 높음
- 화면에 글자가 많이 얹힌 영상은 피함(글자는 편집 단계에서 얹는 편이 깔끔)
저장이 어려우면 화면 녹화: 맥 `Shift + Command + 5`, 윈도우 `Windows + G`.

### STEP 2. 영상을 사진으로 자르기 (3분)
Claude는 채팅에 올린 영상을 재생하지 못하고 사진은 읽으므로, 장면 지점을 사진으로 잘라 올린다.
1. 1초에 한 장씩 (frames 폴더에 `frame_01.jpg`부터 생기면 성공)
```bash
mkdir -p frames
ffmpeg -i reference.mp4 -vf fps=1 frames/frame_%02d.jpg
```
2. 장면이 자주 바뀌면 컷 전환 지점만 추출(열 장이 넘으면 `0.3`을 `0.5`로)
```bash
ffmpeg -i reference.mp4 -vf "select='gt(scene,0.3)'" -vsync vfr frames/scene_%02d.jpg
```
3. 터미널을 안 쓰면 Ezgif 영상→JPG 변환기(https://ezgif.com/video-to-jpg)에 올리고 초당 장수를 1로 두고 내려받기.
4. 사진은 6~9장이면 충분. 시작·중간·끝, 그리고 움직임이 가장 큰 순간을 꼭 포함.

### STEP 3. Claude에게 프롬프트로 번역시키기 (2분)
잘라 둔 사진을 전부 Claude 채팅에 올리고 아래 요청을 보낸다.

프롬프트 뼈대 B. 레퍼런스 사진 → 영상 생성 프롬프트 번역
- 목적: 올린 사진들(순서대로 자른 모션 그래픽)을 영상 생성 AI용 프롬프트로 변환
- 슬롯: [만들려는 것: 예 우리 제품 사진으로 같은 느낌의 4초 광고], [바꿔야 할 대상: 예 초콜릿 바 대신 텀블러], [최종 길이: 4/6/8/10초], [화면비: 가로/세로]
- 한 문단에 담을 5요소: ① 샷과 움직임(피사체 크기, 카메라 움직임) ② 스타일(전체 인상·화질감·심도·모션 블러) ③ 조명(방향과 효과) ④ 장소(배경·바닥·색) ⑤ 동작(화면 안에서 순서대로 일어나는 일)
- 규칙: 사진에서 실제로 보이는 것만 쓰고 안 보이는 부분은 지어내지 말고 빠졌다고 표기 / 브랜드명·로고는 넣지 말고 `<내 제품>`처럼 교체 자리로 남김 / 프롬프트 하나에 동작 하나(장면 둘이면 프롬프트 둘) / 마지막에 바꿔 볼 만한 단어 3개를 따로 제시

장면마다 프롬프트가 한 덩어리씩 오면 성공. 5요소는 영상 모델 공식 안내서가 꼽는 요소라 하나라도 비면 모델이 매번 다르게 채운다. 카메라 용어를 직접 넣어도 된다: `one continuous shot`(끊김 없는 한 컷), `static`/`locked off`(고정), `push in`(밀고 들어감), `punch in`(확 당김), `dolly zoom`(배경 늘어남).

### STEP 4. Google Flow에서 생성 (3분)
1. https://flow.google.com/ 에서 프로젝트를 열고 프롬프트 상자의 모델 이름 클릭 → Video → Omni Flash. (모델을 안 바꾸면 기본값인 이미지 모델이라 사진 한 장이 나옴)
2. 화면비(가로/세로), 출력 수, 모델(Omni Flash), 길이(4/6/8/10초) 설정
3. STEP 3에서 받은 프롬프트를 붙여넣고 생성 → 몇 분 뒤 클립
4. 크레딧 (구독 없이도 매일 50개 지급)
| 해상도 | 4초 | 6초 | 8초 | 10초 |
|---|---|---|---|---|
| 720p | 7 | 10 | 12 | 15 |
| 360p | 4 | 5 | 6 | 7 |
5. 절약 순서(아래 별도 절 참고): 360p 4초로 구도 확인 → 마음에 든 프롬프트만 720p. 유료 구독이면 360p→720p 업스케일은 0크레딧.
6. 구독이 없으면 이용이 몰리는 세계표준시 02~05시(한국 오전 11시~오후 2시)에는 영상 생성이 막힐 수 있다.

### STEP 5. 마음에 안 드는 곳만 말로 고치기 (5분, 선택)
Omni Flash는 앞선 지시를 기억하므로 전체를 다시 쓰지 않고 한 번에 한 가지씩 요청한다(예시):
```
배경만 짙은 남색으로 바꿔 주세요. 나머지는 그대로 두세요.
```
```
카메라 각도를 조금 더 낮게, 아래에서 올려다보는 각도로 바꿔 주세요.
```
```
부스러기가 퍼지는 속도를 절반으로 느리게 해 주세요.
```
바뀐 부분만 다른 클립이 돌아오면 정상. 한 문장에 배경+각도+속도를 몰아넣으면 장면이 통째로 새로 만들어지니 고칠 것이 셋이면 세 번 나눠 말한다. 내 컴퓨터의 영상을 올려 고치는 것도 되지만 길이·화질과 무관하게 1회 40크레딧(하루 무료분 50개를 거의 소진).

### STEP 6. 같은 톤으로 여러 컷 만들기 (10분, 선택)
여러 장면을 이어 붙일 때만. 프롬프트만으로는 컷마다 제품 모양·색이 달라진다.
1. 프롬프트 상자의 모델 이름 → Video 다음에 Ingredients(재료)를 선택하면 이미지 자리가 열린다. 제품/인물 참고 이미지를 올리고 글에서 재료 사용법을 설명:
```
올린 텀블러가 크림색 배경 위에 서 있고, 카메라가 텀블러를 중심으로 천천히 한 바퀴 돕니다.
고급 광고 사진 느낌, 얕은 심도, 왼쪽 위에서 들어오는 부드러운 빛.
```
2. 재료 사진은 배경이 빈 단색 배경 제품 사진이 좋다(공식 권고). 이미지와 글이 어긋나면(붉은 배경 사진 + "흰 배경" 서술) 모델이 흔들린다.
3. 시작·끝 장면을 정하려면 Frames: 첫/마지막 프레임에 이미지를 넣고 사이에 일어날 일을 글로 적는다. 전환 효과나 반복 재생 루프 클립에 사용.

### 하루 50크레딧으로 버티는 순서
1. 360p 4초로 구도·동작만 확인(4크레딧)
2. 프롬프트 단어 두세 개만 바꿔 두세 번 더 돌림
3. 가장 나은 프롬프트를 720p 8초로 재생성(12크레딧)
4. 유료 구독이면 마음에 든 360p 결과를 업스케일(0크레딧)
요금제 월 크레딧(매일 50개에 추가): Plus 200, Pro 1,000, Ultra는 요금제에 따라 10,000 또는 25,000. 남은 크레딧은 다음 달로 이월되지 않는다.

## 핵심 팁 · 주의사항
- 한 줄짜리 프롬프트("멋진 광고처럼")는 매번 결과가 다름 → 5칸을 채우면 반복 가능
- 한 클립에 동작 두 개(갈라지고 회전) 금지 → 클립 둘로 나눠 편집에서 붙이기
- 사진 3장만 올리면 중간 움직임을 추측 → 큰 움직임 포함 6장 이상
- 모델을 안 바꾸고 생성(기본값 이미지 모델) → 사진 1장이 나옴
- 클립은 한 번에 최대 10초(이어 붙이기 기능은 준비 중), 긴 영상은 여러 클립을 편집에서 연결
- 소리도 같이 생성됨, 불필요하면 프롬프트 끝에 "대사 없음". 특정 목소리 유지는 재료를 쓰는 생성에서만 목소리 참고 가능
- 세로 영상 가능(화면비에서 세로 선택, 릴스·쇼츠는 처음부터 세로)
- 결과가 레퍼런스와 많이 다르면 프롬프트의 동작 문장을 먼저 점검: 무엇이 어떤 순서로 움직이는지 한 문장으로 있어야 함
- 무료 크레딧은 그날 처음 생성한 시점 기준 다음 날 재충전, 이월 없음
- 영상 파일을 Claude에 그대로 올리면 안 읽힘(채팅은 문서·이미지만)
- 사진이 9장을 넘으면 장면별 중요도 구분이 어려워짐

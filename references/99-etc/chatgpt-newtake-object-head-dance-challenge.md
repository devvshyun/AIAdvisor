# ChatGPT·뉴테이크로 인외 캐릭터 챌린지 영상 만들기
- 원문: https://lazyowen.com/guides/chatgpt-newtake-object-head-dance-challenge
- 도구·주제: ChatGPT + Newtake 플러그인 · 챌린지 영상 캐릭터 교체 (2026-10-30 공개, 읽는 데 4분, 섹션 3개)
- 한 줄 요약: 얼굴만 사물이고 몸은 사람인 "인외" 캐릭터 이미지를 만든 뒤, 챌린지 영상 속 댄서 두 명만 그 캐릭터로 교체한 15초 무음 영상을 만든다.

## 언제 쓰나
- 유행하는 댄스 챌린지 영상을 안무·카메라·컷 타이밍은 그대로 두고 캐릭터만 바꿔 만들고 싶을 때
- 캐릭터 사진부터 영상까지 ChatGPT 대화창 안에서 이어서 하고 싶을 때

## 준비물 / 필요 도구
- Newtake 가입(홍보 링크 포함): https://www.newtake.ai/?sourceId=NT920396
- Newtake 플러그인 페이지: https://www.newtake.ai/ko/plugin (ChatGPT 탭의 설치 안내 문구를 복사)
- 마켓플레이스 저장소: https://github.com/newtake-ai/marketplace.git
- ChatGPT, 따라 할 챌린지 레퍼런스 영상(댄서 2명 기준)
- PDF: A4 3쪽
- 비용: 페이지에 요금 정보 없음

## 단계별 방법
**1. ChatGPT에 뉴테이크 플러그인 설치하기**
1. 플러그인 페이지의 ChatGPT 탭에서 안내 문구를 복사해 ChatGPT 대화창에 붙여넣어 전송 → ChatGPT가 설치 명령 두 줄을 대신 실행. 문구 구조: ① 마켓플레이스 추가 ② 플러그인 설치 ③ 새 작업을 시작한 뒤 Newtake 계정 인증을 완료하고 준비되면 알려 달라는 요청
```bash
codex plugin marketplace add https://github.com/newtake-ai/marketplace.git --ref main
codex plugin add newtake@newtake
```
   (명령이 `codex` 로 시작함 — 페이지 설명은 ChatGPT에 붙여넣는 방식이지만 실제 실행되는 것은 Codex 플러그인 명령)
2. 설치가 끝나면 새 작업을 연다. 뉴테이크 로그인 창이 뜨면 가입한 계정으로 로그인. 로그인까지 끝나야 아래 프롬프트가 뉴테이크로 이미지·영상을 만듦

**2. 인외 캐릭터 사진 만들기**
- 뉴테이크를 연결한 ChatGPT 새 작업에 한 줄 프롬프트 전송: "한국풍 테마파크 인외를 만들어줘. 얼굴만 사물이고 몸은 사람이고 복장은 사물에 맞춰줘"
- 청사초롱·부채처럼 한국풍 사물이 머리가 되고 옷은 그 사물의 색·무늬를 따라감
- 여러 장이 나오면 마음에 드는 캐릭터를 고름. 챌린지에 댄서가 두 명이면 두 명 선택

**3. 챌린지 영상 속 댄서를 캐릭터로 바꾸기**
- 챌린지 영상 + 고른 캐릭터 사진 2장을 첨부. 순서가 중요: 청사초롱 캐릭터를 첫 번째, 부채 캐릭터를 두 번째로 (첨부 순서가 A/B 배정을 결정)
- 영상 프롬프트 뼈대(영어 원문은 원문 페이지에서 복사):
  - 목적: 15초 댄스 레퍼런스 영상의 사람 댄서 2명을 첨부한 사물 얼굴 캐릭터 2명으로 교체
  - 유지할 것(레퍼런스를 시간 기준으로 정확히 따름): 안무·제스처·리듬·몸 궤적·무대 위치·카메라 움직임·샷 크기·손 디테일 인서트·컷 타이밍·흰 사이클로라마 스튜디오·15초 길이. 출연자는 정확히 2명, 레퍼런스에서 둘이 같이 나오는 곳엔 같이 유지
  - 하지 말 것: 정지 이미지를 따로 애니메이션화, 분할 화면, 사람 얼굴·머리카락 노출, 사물에 동물 머리/눈/입 추가, 로봇 관절·인형 해부, 팔다리 추가, 중복 출연자, 머리 교체, 옷 변경, 자막·로고·새 대사·새 음악·효과음
  - CHARACTER A(첫 번째 이미지): 이목구비 없는 파랑(상)/빨강(하) 직사각 청사초롱 머리, 짧은 코발트 크로스오버 재킷, 아이보리 이너셔츠와 칼라, 빨간 리본, 네이비 바지, 검정 장갑·검정 댄스 스니커즈. 앞쪽/화면 오른쪽에서 시작하는 갈색 머리 댄서에 일관 배정
  - CHARACTER B(두 번째 이미지): 이목구비 없는 아이보리 펼친 접부채 머리(옥색 테두리·금빛 등 문양), 아이보리 크로스오버 재킷, 옥색 주름 짧은 오버스커트, 아이보리 바지, 흰 장갑·아이보리 앵클부츠. 뒤쪽/화면 왼쪽에서 시작하는 검은 머리 댄서에 배정
  - 공통: 교차·편집 중에도 정체성 유지, 몸은 현실적인 성인 사람 댄서가 실제 맞춤 무대복을 입은 상태(머리만 사물), 랜턴 틀·부채 실루엣은 단단하고 일관되게 머리 움직임을 따름, 레퍼런스의 손동작을 장갑·소매와 함께 재현, 천 물리·발 접지·자연스러운 사람 움직임 유지
  - 출력: 같은 16:9 구도, 720p, 오디오 합성 금지(원곡은 생성 후 로컬에서 따로 합성한다는 전제)
- 응용: CHARACTER A·B 설명과 댄서 배정 문장만 내 캐릭터/영상에 맞게 교체
- 결과는 소리 없는 16:9 720p 약 15초 영상. 원본 챌린지 음악은 편집할 때 직접 얹기

## 핵심 팁 · 주의사항
- 로그인까지 완료해야 생성 가능
- 첨부 순서(청사초롱=A 먼저, 부채=B 두 번째)와 "앞/갈색 머리=A, 뒤/검은 머리=B" 배정 문장이 교차 장면에서도 캐릭터가 뒤바뀌지 않게 함
- 결과물은 무음 → 원곡·음악 사용권은 편집 단계에서 직접 확인(페이지 언급 없음, 일반 주의)
- 레퍼런스 영상의 출연자·음악 권리는 본인 책임 (페이지 언급 없음, 일반 주의)

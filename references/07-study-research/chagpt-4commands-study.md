# ChatGPT 공부 명령어 4개 (요약 → 퀴즈)
- 도구·주제: ChatGPT (+ Study Mode, Anki, mermaid.live) · 학습 / 복습
- 한 줄 요약: Cheat Sheet → Blueprint → Flashcards → Mind Map 4개 명령어를 같은 채팅에서 주제만 바꿔 보내 요약부터 퀴즈까지 이어간다. (2026-08-19 공개, 읽는 데 10분 / 따라 하면 약 40분, 7단계. 제목의 "25분"은 핵심 4단계 기준)

## 언제 쓰나
- 시험 대비/새 분야 입문 시 핵심 요약, 학습 순서, 암기 카드, 구조도를 빠르게 만들고 싶을 때
- 답을 받기만 하고 직접 풀어 보지 않아 기억에 안 남을 때 — 같은 주제를 네 번 다르게 물어 요약본·구조 지도·퀴즈 카드·전체 그림을 한 채팅에 쌓음
- 이 네 개는 ChatGPT 내장 버튼이 아니라 "말하는 방식"(프롬프트)이라 설치·결제 불필요

## 준비물 / 필요 도구 (이름 + 공식 링크)
- ChatGPT https://chatgpt.com/ (무료 계정으로 충분)
- Study Mode 안내(OpenAI): https://help.openai.com/en/articles/11780217-using-study-mode · 바로 켜기 https://chatgpt.com/studymode
- mermaid.live https://mermaid.live/ (무료) · Mermaid mindmap 문법 https://mermaid.js.org/syntax/mindmap.html
- Anki https://apps.ankiweb.net/ (무료) · 가져오기 문서 https://docs.ankiweb.net/importing/text-files.html
- (선택) 수업 자료/교재 사진 — 첫 명령 전에 `+` 버튼으로 업로드

## 단계별 방법
**Quick Start**: 새 채팅에서 위에서부터 한 줄씩 붙여넣기(주제 자리에 내 주제).
```
Cheat Sheet: 지도학습 분류
Blueprint: 지도학습 분류
Flashcards: 지도학습 분류
Mind Map: 지도학습 분류
```

1. **STEP 1 주제 한 줄 정하기 (3분)**: 한 번에 공부할 크기로 좁힘("경제학"은 넓고 "수요와 공급 곡선"은 적당). 여기에 **내 수준 + 쓸 곳**을 붙여 메모해 두고 네 단계에 계속 사용. 예: `지도학습 분류. 대학교 1학년 수준. 금요일 시험 대비`. 수준을 안 붙이면 너무 어렵거나 뻔한 내용이 나옴.
2. **STEP 2 Cheat Sheet (5분)**: 새 채팅에서
   ```
   Cheat Sheet: 지도학습 분류. 대학교 1학년 수준. 금요일 시험 대비
   ```
   - 핵심 개념·공식·용어 정의가 담긴 한 페이지. 항목이 20개 넘게 쏟아지면 너무 넓게 잡은 것 → 주제를 좁혀 재전송. 마음에 안 들 때: "너무 어려워요. 처음 배우는 사람 기준으로 다시 정리하고, 어려운 용어는 옆에 쉬운 말로 풀어 주세요". 이후 퀴즈에서 틀렸을 때 돌아올 기준표이므로 채팅을 닫지 말 것.
3. **STEP 3 Blueprint (5분)**: 같은 채팅에서
   ```
   Blueprint: 같은 주제
   ```
   - 학습 순서, 개념 간 연결, 초급→고급 경로. 앞 치트시트를 기억하므로 주제 재입력 불필요. 이어서 "이 중에서 시험에 자주 나오는 부분과, 초보자가 제일 많이 헷갈리는 부분을 각각 알려 주세요"를 보내면 우선순위 목록(공부 시간 부족할 때 여기부터).
4. **STEP 4 Flashcards 퀴즈 (7분)**: 
   ```
   Flashcards: 같은 주제, 20장
   ```
   - 앞면 질문/뒷면 답 카드 20장. 그대로 읽으면 의미가 없으므로 이어서 요청(뼈대): 한 장씩 퀴즈로 내고, 내 답을 먼저 받고 채점, 틀리면 치트시트의 어느 항목을 다시 볼지 알려 달라. 정답을 먼저 말하면 "답을 먼저 알려주지 말고, 힌트만 주고 다시 물어봐 주세요". 다 풀면 "제가 틀린 문항만 모아서 다시 정리해 주세요. 왜 틀렸는지 이유도 한 줄씩 붙여 주세요" → 약점 목록(시험 직전용). (능동 회상 = 답을 보기 전에 먼저 떠올려 보는 공부법)
5. **STEP 5 Mind Map (5분)**: 
   ```
   Mind Map: 같은 주제
   ```
   - 중심 주제 아래 계층형 글자 구조. 그림으로 보려면: "이 마인드맵을 Mermaid mindmap 문법의 코드 블록으로 만들어 주세요" → `mindmap`으로 시작하는 코드 블록을 mermaid.live 왼쪽 칸에 붙여넣으면 오른쪽에 그림, 우상단에서 이미지 저장.
6. **STEP 6 Study Mode (5분)**: 정답 대신 질문·힌트로 이끄는 공식 기능(무료 포함 모든 요금제, 웹/iOS/안드로이드).
   - 웹: 입력창에 `@study` 입력 또는 `+` → study 검색 → Study 선택(또는 chatgpt.com/studymode). iOS: `+` → 도구 목록에서 Study. 안드로이드: `+` → Plugins → Study 검색·선택. 입력창에 Study 표시가 붙으면 활성.
   - 요청 뼈대: "이 주제로 저를 가르쳐 주세요. 제가 어디까지 아는지 먼저 물어보고, 한 번에 한 단계씩 진행해 주세요" → 설명 대신 질문이 먼저 돌아옴. 너무 빠르면 "한 단계마다 멈추고 제가 이해했는지 물어봐 주세요", 너무 쉬우면 "기본은 압니다. 더 어려운 문제로 시험해 주세요".
   - 끄기: 입력창의 Study 표시를 백스페이스로 지우거나 × 클릭. 일반 채팅·임시 채팅에서만 가능(GPT/프로젝트 대화에선 안 켜짐 → 새 일반 채팅).
7. **STEP 7 Anki로 반복 (선택, 10분)**: 같은 채팅에서 요청 뼈대: 위 플래시카드 20장을 **세미콜론으로 구분한 표**(한 줄에 카드 하나, 앞면;뒷면 순서, 설명 없이 표만)로. → `질문;답` 줄 20개를 메모장에 붙여 `.txt`(UTF-8)로 저장 → Anki `File > Import`로 선택 → 미리보기 확인 후 덱에 20장. 한글이 깨지면 UTF-8로 저장.

**설치·진행 위임 프롬프트 뼈대(ChatGPT 새 채팅)**: 역할=학습 도우미(자료 4종 제작 + 퀴즈). 슬롯 `<내 주제>`, `<내 수준>`, `<쓸 곳>`. 작업: ① 이 채팅에서 파일 업로드·Study Mode 사용 가능 여부 먼저 안내(불가하면 그 기능 없이 진행법) ② `Cheat Sheet:` → `Blueprint:` → `Flashcards:` 20장 → `Mind Map:` 순서로 **하나씩** 만들고 다음으로 ③ 플래시카드를 한 장씩 퀴즈(내 답 먼저 받고 채점, 틀리면 치트시트 항목 짚기) ④ 네 자료의 용도를 5줄 이내로 설명. 제약: 내가 답하기 전에 정답 금지, 불확실한 건 지어내지 말고 모른다고 말하기, 반드시 이 채팅 안에서 이어서. 검증: 자료 4종이 채팅에 모두 있고 퀴즈 최소 5문항 채점 결과 존재. 빠지면 완료 선언 금지.

## 핵심 팁 · 주의사항
- 네 명령은 **같은 채팅**에서(나누면 앞 내용을 기억 못 해 매번 주제를 다시 물음). 채팅을 바꿨다면 STEP 1 주제 문장부터 다시.
- 길면 숫자로 제한: "한 페이지", "카드 20장만", "핵심 10개만".
- AI 답은 틀릴 수 있음(OpenAI도 Study Mode의 실수 가능성을 안내) → 시험·과제는 교재/수업 자료와 대조, "이 내용의 근거를 알려 주세요"로 확인.
- 이전 학습을 이어 가려면 Settings > Personalization에서 Memory 켜기(꺼져도 학습은 되지만 매번 수준을 알려야 함).

## 문제 해결
- 퀴즈인데 답까지 같이 나옴: "답을 먼저 알려주지 말고 힌트만 주세요" 재전송 → 그래도면 Study Mode 사용.
- Study 버튼이 안 보임: GPT/프로젝트 대화에선 없음 → 새 일반 채팅 또는 chatgpt.com/studymode.
- 결과가 너무 김: 분량 숫자 지정 후 재전송.

# DESIGN.md: AIAdvisor 데모 페이지

이 페이지는 스킬에 들어 있는 웹 디자인 가이드(`references/09-web-design/`)를 따라 만들었습니다. 가이드가 공통으로 강조하는 순서대로, 화면을 만들기 전에 이 기준 파일을 먼저 정했습니다.

## 브리프
- **무엇**: Claude Code 스킬 AIAdvisor의 소개·데모 페이지 (GitHub Pages, 정적 HTML 한 장)
- **누가 보나**: Claude Code를 쓰는 한국어 개발자. 이미 도구를 여러 개 깔아 봤고 "뭘 더 깔아야 하지"를 고민하는 사람
- **느낌**: 차분하고 믿음직한 현장 매뉴얼. 화려한 랜딩보다 잘 정리된 색인과 터미널 기록에 가깝게
- **핵심 행동**: 설치 명령 복사 (버튼은 한 종류만)

## 색
| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--paper` | `#F3F0E8` | `#121315` | 페이지 배경 |
| `--surface` | `#FBFAF6` | `#1A1C1F` | 터미널·표 등 한 단계 떠 있는 면 |
| `--ink` | `#17191C` | `#ECE9E2` | 본문·제목 |
| `--muted` | `#565A61` | `#A3A7AE` | 보조 글자 (배경 대비 4.5:1 이상) |
| `--rule` | `#D6D0C3` | `#2E3135` | 구분선 |
| `--accent` | `#A8380A` | `#F08A4B` | 주조색 하나 (주홍). 링크, 강조, 버튼 |
| `--accent-soft` | `#F4E1D3` | `#3A2418` | 선택된 탭, 강조 배경 |

주조색은 주홍 한 가지만 씁니다. 상태 표시가 필요할 때도 새 색을 만들지 않고 굵기와 기호로 구분합니다.

## 글꼴
- 제목: **Noto Serif KR** 600·700. 편집물 같은 무게감
- 본문: **Pretendard Variable**. 한글 가독성
- 코드·터미널: **JetBrains Mono**, 한글이 섞이면 Pretendard로 대체
- 본문 17px / 줄 간격 1.7, 제목은 `clamp()`로 화면 폭에 맞춰 조정

## 간격과 배치
- 최대 폭 1120px, 좌우 여백은 모바일 20px, 데스크톱 40px
- 섹션 간격: 데스크톱 112px, 모바일 72px
- 히어로는 왼쪽 정렬 비대칭(글 7 : 터미널 5). 가운데 정렬 히어로는 쓰지 않음
- 구역은 카드가 아니라 1px 선과 여백으로 나눔. 둥근 모서리는 4px 이하

## Taste 다이얼
- `DESIGN_VARIANCE` 6: 비대칭이지만 읽기 쉽게
- `MOTION_INTENSITY` 2: 상태가 바뀔 때 150ms 페이드만. 스크롤 효과·바운스 없음
- `VISUAL_DENSITY` 4: 여백을 넉넉히, 표 안에서만 촘촘하게

## 금지 목록 (가이드의 "AI 티 다섯 가지" + 추가)
- Inter, Roboto, 시스템 기본 글꼴만 쓰기
- 보라→파랑 그라데이션, 무작위 유리 효과
- 카드 안의 카드, 똑같은 카드 세 장 나열
- 색 있는 배경 위 회색 본문
- 튕기는 바운스, 끝없이 반복되는 장식 애니메이션
- AI 생성 이미지, 의미 없는 장식 아이콘
- 제목 위의 작은 영문 라벨(eyebrow). 제목이 스스로 무게를 갖게 하고 라벨은 쓰지 않음
- 01·02 같은 섹션 번호, MODE 1 같은 태그
- 큰 숫자 하나에 작은 설명을 붙이는 지표형 강조
- 콜아웃이나 선택 항목에 두꺼운 색 왼쪽 줄
- 코드가 아닌 곳의 모노스페이스. 모노는 터미널 출력과 명령에만 씀
- ✓, +, − 같은 문자로 아이콘을 대신하기. 필요하면 SVG로 그림
- 제목 속 한 구절만 주조색으로 칠하는 강조
- 브라우저 기본값 방치: 텍스트 선택색, 스크롤바, 캐럿 색은 팔레트에서 지정

## 접근성 (Web Design Guidelines 기준)
- 모든 버튼·탭에 보이는 포커스 링 (`:focus-visible`, 주조색 2px)
- 탭은 `role="tablist"`와 방향키 이동 지원
- 복사 결과는 `aria-live`로 알림
- `prefers-reduced-motion`이면 모든 전환을 끔
- `prefers-color-scheme`으로 다크 모드 지원

## 확인 방법
- 데스크톱(1280px)과 모바일(375px) 화면을 캡처해 간격·넘침·정렬을 확인
- `npx --yes impeccable@latest detect docs/`로 AI 티 자동 검사. 이번 제작 환경에서는 감지 도구의 파서 모듈이 없어 결과를 믿을 수 없었고, 대신 위 금지 목록을 기준으로 코드를 직접 점검했습니다. 파서가 갖춰진 환경에서 한 번 더 돌려 보세요
- 라이트·다크 두 모드에서 모든 글자의 명암비가 4.5:1 이상인지 스크립트로 확인

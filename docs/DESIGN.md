# DESIGN.md: AIAdvisor 데모 페이지

제품 맥락은 저장소 루트의 `PRODUCT.md`에 있습니다. 이 파일은 화면의 기준입니다. 스킬 속 웹 디자인 가이드(`references/09-web-design/`)가 권하는 순서대로 화면보다 먼저 정했고, emil-design-eng(모션·호버)과 design-taste-frontend(레이아웃·카피) 스킬의 기준을 함께 반영했습니다.

## 방향
**갤러리의 도록.** 흰 벽에 작품 하나씩 걸듯, 한 화면에 생각 하나. 큰 글자와 빈 공간이 주인공이고 색은 거의 쓰지 않는다. 제품 화면(예시 출력)만 어두운 바탕 위에 실제 UI처럼 놓는다.

## 색
| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--bg` | `#F5F4F0` | `#0E0E0D` | 페이지 바탕 |
| `--ink` | `#121211` | `#EDEBE6` | 글자 |
| `--muted` | `#5E5C57` | `#A09D96` | 보조 글자 (명암비 4.5:1 이상) |
| `--line` | `#D9D6CE` | `#2A2927` | 구분선 |
| `--accent` | `#B4410F` | `#F0874A` | 주홍. 페이지 전체에서 링크 밑줄, 커서 깜빡임, 선택 표시에만 |
| `--stage` | `#121211` | `#161615` | 예시 출력이 놓이는 어두운 무대 (한 번만) |

주조색은 아껴 쓴다. 한 화면에 주홍이 두 군데 넘게 보이면 줄인다.

## 글꼴
- 큰 제목: **Noto Serif KR** 300·400. 가는 명조를 크게 써서 우아함을 만든다 (Hahmlet은 큰 크기에서 세리프 대비가 약해 교체)
- 본문·UI: **Pretendard Variable** 400·500·600
- 라틴 강조(로고, 꼬리말 워드마크): **Instrument Serif** 이탤릭
- 명령·터미널: **JetBrains Mono**
- 제목 자간 -0.035em, 본문 17px/1.75, 본문 폭 65자 이하

## 간격
- 최대 폭 1280px, 좌우 여백 `clamp(20px, 5vw, 72px)`, 양쪽 끝선을 모든 블록이 공유
- 섹션 사이 `clamp(120px, 18vh, 220px)`. 첫 화면은 100svh를 혼자 쓴다
- 카드 없음. 구분은 1px 선과 여백으로만

## 모션 (MOTION_INTENSITY 6)
- 곡선: 나타남 `cubic-bezier(0.23, 1, 0.32, 1)`, 화면 위 이동 `cubic-bezier(0.77, 0, 0.175, 1)`
- **연출된 순간은 하나**: 첫 화면 제목이 줄마다 아래에서 떠오른다 (1100ms, 줄 간격 90ms)
- 스크롤 등장: 섹션 제목은 줄 가리개 안에서 올라오고(900ms), 본문은 투명도와 16px 이동으로 한 번만 나타난다(700ms, 형제 사이 60ms 시차). 모든 요소를 같은 방식으로 띄우지 않는다
- 버튼·탭·복사 같은 UI 반응은 300ms 이하. 누르면 `scale(0.97)`
- 호버는 `(hover: hover) and (pointer: fine)`에서만. 밑줄이 왼쪽에서 그려지고, 목록 행은 글자가 6px 밀리며 화살표가 나타난다
- `prefers-reduced-motion`: 이동은 모두 끄고, 내용은 처음부터 보인다. 스크립트가 없어도 내용은 보인다

## 레이아웃 (DESIGN_VARIANCE 7, VISUAL_DENSITY 2)
- 첫 화면: 큰 제목이 폭을 채우고, 아래 끝에 설명과 설치 명령
- 두 번째 화면: 어두운 무대 위 예시 출력 (제품 UI)
- 그다음은 한 화면에 생각 하나: 두 모드, 약속 한 문장, 가이드 목록, 설치, 질문
- 꼬리말: 화면 폭을 채우는 워드마크

## 금지 목록
- Inter, Roboto, 시스템 기본 글꼴만 쓰기 / 보라 계열, 그라데이션, 유리 효과
- 카드 안의 카드, 같은 카드 반복, 제목 위 영문 라벨, 01·02 섹션 번호, 지표형 큰 숫자
- 두꺼운 색 왼쪽 줄, 문자로 그린 아이콘, 코드가 아닌 곳의 모노스페이스
- 섹션마다 똑같은 페이드인, 바운스, 기울이기, 패럴랙스, 커스텀 커서
- 사진·이미지 아래 설명문, 지어낸 후기·숫자

## 접근성
- 포커스 링은 주홍 2px, 탭은 방향키 이동, 복사 결과는 `aria-live`로 알림
- 라이트·다크 모두 글자 명암비 4.5:1 이상

## 확인 방법
- 1440·1024·768·390px 폭에서 캡처해 간격, 넘침, 양쪽 끝선을 확인
- 움직임 줄이기 설정과 스크립트 없는 상태에서 내용이 모두 보이는지 확인
- `npx --yes impeccable@latest detect docs/`로 AI 티 자동 검사 (파서 모듈이 있는 환경에서)

02 · 동작 방식

추천이 나오기까지 세 단계

말한 내용과 폴더 상태를 보고 보완 모드와 신규 모드 중 하나를 고릅니다. 어느 쪽이든 읽고, 고르고, 정리한 다음 멈춥니다.

  1. 01
    프로젝트와 환경을 읽습니다

    CLAUDE.md, README, 의존성 파일, 최근 git log, 이미 깔린 MCP·스킬·플러그인을 확인합니다. 읽기만 합니다.

  2. 02
    레시피와 카탈로그부터 봅니다작은 색인에서 맞는 레시피와 도구 고르기

    작은 색인에서 맞는 레시피와 도구를 고르고, 이미 있는 도구와 역할이 겹치는 도구, 관리가 멈춘 도구는 뺍니다. 그 밖의 주제는 가이드를 엽니다.

  3. 03
    정리하고 번호를 기다립니다추천 표와 실행 계획을 내고 멈춤

04 · 질문

자주 묻는 질문

더 궁금한 점은 저장소에 남겨 주세요. GitHub 이슈 열기

Q1

스킬이 마음대로 뭔가를 설치하나요?

아니요. 추천 단계에서는 읽기만 합니다. "2번이랑 3번 진행해줘"처럼 고른 다음에 설치를 시작합니다.

Q2

추천 근거는 최신인가요?

카탈로그는 항목마다 확인한 날짜가 있고, 30일이 넘은 항목은 바뀌었을 수 있다고 표시합니다. 매달 1일 저장소 상태를 자동으로 점검하고, "카탈로그 갱신해줘"라고 하면 그날 기준으로 다시 조사합니다. 가이드 —편은 2026-11-05 기준입니다.

Q3

Windows에서도 되나요?

됩니다. 현재 OS를 확인하고 명령을 PowerShell이나 Git Bash에 맞게 바꿔 보여 줍니다.

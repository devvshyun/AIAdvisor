# 시안 B · bun.sh 기준

- 서체: 제목은 아주 굵고(900) 자간을 바짝 좁힌 짧은 블록, 본문은 가는 산세리프(Inter 300~400 + Pretendard), 라벨·버전·축 눈금·명령은 고정폭(JetBrains Mono). 크기 단계는 큰 제목 → 15px 본문 → 11~12px 고정폭 라벨로 셋.
- 색 역할: 흰 바탕, 검정은 제목·버튼·선택된 탭·막대, 회색 #f4f4f4는 선택된 행과 막대 트랙, 코드 블록만 거의 검정. 강조색은 하나(파랑 #2b4cff, bun의 분홍은 안 씀)를 "가장 빠른 값"·선택 표시·NEW 태그에만.
- 여백·그리드: 양옆 세로 구획선이 있는 1136px 레일, 섹션 사이는 가로 1px 선, 왼쪽 글/오른쪽 데이터 패널 2단, 섹션 위아래 64~72px로 빽빽하게.
- 장식: 검은 테두리 데이터 패널 + 위쪽 세그먼트 탭, 가로 막대 그래프와 축 눈금, 모서리 한쪽을 깎은 검은 설치 명령 블록, 번호(01~05) 목록에서 선택 행만 회색 바탕 + 아래 강조선, 패널 아래 작은 각주.
- 버린 것: 로고·마스코트, 분홍 강조색, "USED BY" 회사 로고 띠(도구 종류 띠로 바꿈), 재생 애니메이션·replay 버튼, 벤치마크 수치(실제 데이터인 준비 시간·도구 수로 대체).

## 실제 페이지로 다듬은 것 (2026-11-09)

- 데이터: 히어로 패널·상황별 결과·추천 근거를 `../data/demo.json`, `../data/catalog.json`에서 `fetch`로 그린다. 개수(도구 46·써 봄 9·가이드 82·레시피 수)도 JSON에서. 불러오지 못하면(스크립트 꺼짐 포함) 각 자리에 "목록을 불러오지 못했습니다. GitHub에서 보기"가 남는다.
- 히어로 패널: 위쪽 탭을 상황 번호 01~05로 바꿨다(이름이 길어 5개가 한 줄에 안 들어감). 막대는 추천 표(B)의 난이도 칸에서 분·시간을 읽어 그리고, 시간 대신 "지금/나중에"인 상황(새 웹앱)은 막대 없이 값만 보인다. 손으로 쓴 각주(읽은 파일 목록)는 데이터에 없어 A~E 항목 이름으로 바꿨다.
- 상황별 결과: 왼쪽 번호 목록이 탭이 되고, 선택 행 설명은 그 상황의 A(진단 요약) 문장을 쓴다. 표는 `.tbl` 안에서만 가로 스크롤.
- 추천 근거: 분야별 막대가 그대로 분야 탭이 된다(선택 행은 회색 바탕 + 파랑 삼각형). 아래에 레시피 단계, 오른쪽에 그 분야 도구 전부("써 봄" 파랑, "관리 중단"은 취소선 배지). 가이드 탭도 주제 막대가 탭이고 오른쪽에 제목(링크)·요약.
- 섹션 id: top·demo·how·kit·faq·guestbook. 내비게이션에 방명록 추가, sticky 메뉴 높이만큼 scroll-margin.
- 방명록: giscus(`data-theme="light"`)를 검은 테두리 고정 높이 상자(560px, 좁은 화면 480px) 안에서 스크롤.
- 컨셉 전환 버튼: `../concept-switch.js` (data-concept="b"). 파비콘은 메뉴의 A 마크를 그대로.
- 확인: 1440×900, 375×812 가로 스크롤 0, 상황 탭 5·히어로 탭 5·분야 탭 3·주제 탭 11 모두 내용이 바뀜. 콘솔 오류는 giscus가 github.com 안내 페이지로 넘기며 생기는 것뿐(기본 페이지도 같음).

  • 유튜브 튜토리얼을 클로드가 실행하는 스킬로 바꾸는 세 가지 세팅클로드에게 영상을 보는 눈(watch 스킬)을 달고, 같은 영상을 Gemini가 두 번째 눈으로 따로 읽게 한 뒤, 두 기록을 SPEC.md로 합쳐 skill-creator로 실제 실행되는 스킬로 굽는 순서.
  • 무료 클로드 스킬로 다섯 부서 채우기재무·법무·마케팅·SNS(+디자인) 스킬 팩을 플러그인으로 설치하고, 복사본을 내 사업에 맞게 고쳐 쓰는 순서.
  • 고객 유치만을 위한 클로드 에이전트(하비/Harvey) 세팅하는 법오픈소스 Harvey를 설치해 내 제품 홈페이지로 학습시키고, 조건에 맞는 업체를 찾아 사이트에서 본 사실로 콜드메일 초안을 쓰고, 내 승인 후 발송·회신 처리를 이어 가게 한다. 영어 메일 기준이라 해외 업체 영업에 적합.
  • 내 아이디어를 6개월 만들기 전에 뜯어보는 네 자리 (아이디어 검토 에이전트 4개)지지자·회의론자·투자자·판사 네 역할을 한 번만 만들어 두고 순서대로 돌려 "만든다 / 고치고 만든다 / 접는다" 중 하나의 판결을 받는다.
  • 클로드로 업체 연락처 수천 개를 무료로 모으는 법무료 오픈소스 ScrapeGraphAI와 내 컴퓨터에서 도는 무료 로컬 모델(Ollama)로 웹페이지의 공개 업체 연락처만 골라 CSV로 모으고, 매일 아침 자동 실행되게 한다.
  • 디자인 스킬 5개 (클로드한테 디자인 시키기 전에 깔 것)Awesome DESIGN.md, Image to Code, Taste, agent-browser, Web Design Guidelines를 순서대로 설치해 디자인 고정→참고 이미지→탈 AI 스타일→자기 검증→배포 전 검사 흐름을 만든다.
  • 클로드로 전문가가 만든 것 같은 웹사이트 만드는 법 (디자인 스킬 3개 + 연결 도구 2개)디자인 기준(스킬 3개)과 확인 도구(MCP 2개)를 설치하고 구체적인 브리프를 줘서 보라색 그라데이션·똑같은 카드 세 장 같은 "AI 티" 나는 사이트에서 벗어난다.
  • AI 티 안 나는 웹사이트, 클로드로 만드는 법스킬 2개 설치 → /impeccable init으로 디자인 기준 파일(PRODUCT.md, DESIGN.md) 저장 → 빌드 요청에 가드레일 추가 → impeccable detect로 AI 티를 자동 검사.
  • 스크롤할 때마다 영상이 움직이는 웹사이트, 한 줄로 만드는 세팅AI가 만든 웹사이트가 밋밋한 이유는 넣을 영상·이미지가 없어서다. 힉스필드를 클로드에 연결하면 클로드가 사이트에 필요한 영상까지 직접 생성해 붙이고 배포까지 한다. 모델은 Fable 5, 추론은 max로 올려 한 문단 주문으로 사이트를 통째로 만든다.
  • 클로드가 남기는 표식 지우기글 속 안 보이는 문자와 이미지/PDF 메타데이터는 도구로 제거·검증할 수 있고, 단어 선택 패턴은 검증 방법이 없다는 한계를 안내한다.
  • AI가 쓴 글은 문체가 아니라 이야기 구조에서 걸립니다 (StoryScope)문체가 아니라 "이야기를 짜는 방식(서사 구조)"으로 AI 소설을 93.2% 가려낸다는 StoryScope 논문을 정리하고, 내 글을 같은 기준으로 진단·수정하는 체크리스트와 프롬프트를 제공한다.
  • ChatGPT·뉴테이크로 인외 캐릭터 챌린지 영상 만들기얼굴만 사물이고 몸은 사람인 "인외" 캐릭터 이미지를 만든 뒤, 챌린지 영상 속 댄서 두 명만 그 캐릭터로 교체한 15초 무음 영상을 만든다.
  • 클로드 코드 돈 안 내고 쓰는 프리 LLM API 세팅법계속 무료로 쓸 수 있는 LLM API 공급자 16곳 목록(+키 설정을 돕는 free-llm-apis 스킬)을 내려받고, 무료 키를 Manifest 라우터에 연결한 뒤, 테스트 폴더 하나의 .claude/settings.json에서만 Claude Code가 무료 모델을 쓰게 하고 되돌리는 4단계.

추천 근거는 최신인가요?

카탈로그는 항목마다 확인한 날짜가 있고, 30일이 넘은 항목은 바뀌었을 수 있다고 표시합니다. 매달 1일 저장소 상태를 자동으로 점검하고, "카탈로그 갱신해줘"라고 하면 그날 기준으로 다시 조사합니다. 가이드 82편은 2026-11-05 기준입니다.

Windows에서도 되나요?

됩니다. 현재 OS를 확인하고 명령을 PowerShell이나 Git Bash에 맞게 바꿔 보여 줍니다.

클라우드 환경의 설정 스크립트에 설치 한 줄을 넣으면 됩니다.

스킬을 지우려면 어떻게 하나요?

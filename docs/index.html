보완 모드

이미 코드가 있는 프로젝트

코드, 설정, git 기록, 지금 깔린 MCP·스킬·플러그인을 읽고 약점을 근거와 함께 찾습니다.

예: 프로젝트에서 보완할 부분 추천해줘

  1. A진단 요약
  2. B추천 작업 표: 효과, 난이도, 비용·리스크
  3. C상위 3개 실행 계획: 지금 OS에 맞춘 명령
  4. D하지 말 것, 보류할 것
  5. E다음에 물어볼 것

신규 모드

빈 폴더, 또는 아이디어만 있을 때

무엇을, 누구를 위해, 어떤 형태와 예산으로 만드는지 빠진 것만 묻고 단계별 시작 세트를 짭니다.

예: 가계부 웹앱 새로 만들 건데 뭐 세팅하면 좋아?

  1. A프로젝트 요약과 가정
  2. B단계별 시작 도구 세트: 지금, 나중에
  3. C첫 주 세팅 계획
  4. D처음부터 깔 필요 없는 것
  5. E다음에 물어볼 것

추천하기 전에 거치는 순서

82편을 한꺼번에 읽지 않습니다. 프로젝트를 먼저 보고, 필요한 문서만 엽니다.

  1. 프로젝트를 읽습니다

    CLAUDE.md, README, 의존성 파일, 최근 git log. 읽기만 합니다.

  2. 지금 환경을 확인합니다

    claude mcp list와 스킬·플러그인 폴더를 보고, 이미 있는 도구는 추천에서 뺍니다.

  3. 필요한 가이드만 엽니다

    상황별 색인에서 후보를 고르고, 역할이 겹치는 도구는 하나만 남깁니다.

  4. 정리하고 기다립니다

    정해진 형식으로 정리한 뒤, 번호를 고를 때까지 멈춥니다.

설치, 설정 변경, 파일 수정은 사용자가 번호를 고른 다음에야 시작합니다.

API 키, 계정 연결, 유료 플랜이 필요한 항목에는 따로 표시가 붙습니다. 가이드는 2026-11-05 기준이라, 실행 전에 공식 문서를 확인하라는 안내도 함께 나옵니다.

스킬에 들어 있는 가이드 82편

모든 가이드가 같은 순서로 쓰여 있습니다. 언제 쓰나, 준비물, 단계별 방법, 팁과 주의사항, 체크리스트.

    설치와 업데이트

    스킬 폴더 이름이 곧 스킬 이름이라서 project-upgrade-advisor 폴더로 받아야 합니다.

    • 받은 뒤 Claude Code 세션을 새로 열면 스킬이 잡힙니다.
    • 업데이트는 스킬 폴더에서 git pull 한 번이면 됩니다.
    • 스킬을 쓸 수 없는 환경이라면 SKILL.md 본문을 대화에 붙여넣어도 같은 순서로 동작합니다.

    git clone https://github.com/devvshyun/AIAdvisor.git ~/.claude/skills/project-upgrade-advisor

    업데이트

    cd ~/.claude/skills/project-upgrade-advisor && git pull

    git clone --depth 1 https://github.com/devvshyun/AIAdvisor.git ~/.claude/skills/project-upgrade-advisor

    자주 묻는 질문

    스킬이 마음대로 뭔가를 설치하나요?

    아니요. 추천 단계에서는 읽기만 합니다. 결과를 보고 "2번이랑 3번 진행해줘"처럼 고른 다음에 설치를 시작합니다.

    가이드 내용은 최신인가요?

    2026-11-05 기준입니다. 도구 버전, 무료 한도, 가격은 바뀔 수 있어서 스킬이 실행 전에 공식 문서를 확인하라고 안내합니다.

    Windows에서도 되나요?

    됩니다. 스킬이 현재 OS를 확인하고 명령을 PowerShell이나 Git Bash에 맞게 바꿔 보여 줍니다. 특정 OS에서만 되는 도구는 그렇다고 밝힙니다.

    클라우드 세션에서도 쓸 수 있나요?

    클라우드 환경의 설정 스크립트에 설치 한 줄을 넣으면 됩니다. 설치 없이 쓰려면 세션에서 이 저장소를 받아 SKILL.md대로 해 달라고 말해도 됩니다.

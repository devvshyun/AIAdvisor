추천이 나오기까지 세 단계

  1. 프로젝트와 환경을 읽습니다

    CLAUDE.md, README, 의존성 파일, 최근 git log, 이미 깔린 MCP·스킬·플러그인을 확인합니다. 이 단계에서는 읽기만 합니다.

  2. 필요한 가이드만 엽니다

    상황별 색인에서 후보를 고르고, 이미 있는 도구와 역할이 겹치는 도구는 뺍니다.

  3. 정리하고 번호를 기다립니다

    추천 표와 실행 계획을 내고 멈춥니다. API 키나 유료 플랜이 필요한 항목은 따로 표시합니다.

설치

git clone https://github.com/devvshyun/AIAdvisor.git ~/.claude/skills/project-upgrade-advisor

ls ~/.claude/skills/project-upgrade-advisor

cd ~/.claude/skills/project-upgrade-advisor && git pull

설치

Get-ChildItem "$env:USERPROFILE\.claude\skills\project-upgrade-advisor"

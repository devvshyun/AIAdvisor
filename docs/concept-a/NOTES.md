# 시안 A · linear.app 기준

- 서체: Pretendard Variable 한 가족만(라틴 포함). 큰 제목은 600 굵기·자간 -0.035em·행간 1.06으로 바짝 조이고, 본문 15px, 라벨은 모노 12px 대문자("FIG 0.1" 식).
- 색 역할: 배경 #08090a 거의 검정, 본문 흰색, 보조 문구 회색 #8a8f98(라벨 회색 #868b93), 테두리는 흰색 8% 머리카락 선. 강조색은 "진행 중" 노란 점 하나뿐, 버튼은 흰색 알약.
- 여백: 72px 상단 바, 히어로 위 160px 비움, 섹션 128px 간격, "왼쪽 큰 제목 / 오른쪽 회색 설명" 2단 머리. 제품 UI(사이드바+본문+속성 칸)를 화면 폭 가까이 크게 보여 줌.
- 장식: 그라데이션·글로우 없음. 세로 머리카락 선으로 나눈 3단 칸과 선만 쓴 아이소메트릭 SVG, 섹션 사이 가로 선이 장식의 전부.
- 버린 것: Linear 로고·문구·고유 아이콘, 실제 브랜드 색 조합, 스크롤 애니메이션.

## 실제 페이지로 다듬은 것 (2026-11-09)
- 상황 탭·분야 탭·가이드 주제 탭과 숫자(도구·레시피·가이드 수)를 `../data/demo.json`, `../data/catalog.json`에서 fetch로 그린다. 표는 `.tbl` 상자에 넣어 좁은 화면에서 표만 가로 스크롤.
- 스크립트가 꺼지거나 fetch가 실패하면 "목록을 불러오지 못했습니다. GitHub에서 보기"를 보인다.
- 섹션 id: top, demo, how, kit, faq, guestbook. 방명록은 별도 섹션으로 빼고 giscus(`dark_dimmed`)를 560px(모바일 440px) 고정 높이 상자 안에서 스크롤.
- 추가한 것: 관리 중단 표시(회색 점), 레시피 묶음 이름 라벨, 가이드 제목·요약 목록, 파비콘, 컨셉 전환 스크립트, 꼬리말 기본 페이지 링크.
- 로컬(8791)에서는 giscus가 막힌다: `giscus.json`의 origins에 localhost:8767과 github.io만 있어서. 배포 주소에서는 정상.
- 점검 반영(2026-11-09): Inter 링크를 지우고 본문·제목을 Pretendard Variable로 통일(모노는 JetBrains Mono 유지). 16px 미만 글자를 15/14/13/12px 네 단계(`--fs-body/list/aux/label`)로 묶고 12px 미만을 없앰. 라벨 회색 `--faint`를 #5c6066 → #868b93으로 밝혀 패널 바탕에서도 4.5:1 이상. 분야별 도구 목록과 가이드 목록은 6개만 보이고 "전체 보기 (N개)"/"접기" 버튼으로 펼치며, 탭을 바꾸면 다시 6개로 돌아감.

## 2차 다듬기(2026-11-09)
- 눈 피로: 면을 세 단계로(페이지 #0e0f11, 카드·띠 #15171a, 패널 #1c1f23). #demo·#kit 섹션을 띠 면 + 위아래 선으로 구획. 글자는 제목 #f4f4f2, 본문 #c9cbd0, 보조 #9a9ea6(순백 본문 없음). 선은 기본 흰색 12%, 강한 선 20%.
- 포인트는 앰버 #f2a93b 하나: 주 버튼(앰버 바탕 + #1a1205 글자), 핵심 숫자(46·3·82 수치 띠, 제목 속 도구 수), 추천 표 1순위 번호와 왼쪽 2px 선, 선택 탭 표시, 링크 마우스 오버. 상태색은 점·라벨에만: 써 봄 초록 #5fbf77, 관리 중단 붉은 #e5665a, 모드 라벨 보완=앰버 옅은 바탕, 신규=회청색 옅은 바탕.
- 타이포: 히어로 38~72px, 섹션 제목 30~44px, 둘 다 #f4f4f2→#a7abb3 위아래 그라데이션 글자. 소제목 20px/600 단계 추가(동작 방식·모드 카드·FAQ·레시피 제목). 숫자는 JetBrains Mono, 수치 띠는 40px(휴대폰 28px). 16px 미만은 12·13·14·15 네 단계 유지.
- 구분: 표 머리줄은 #23272c 면, 줄마다 선, 줄 마우스 오버 시 살짝 밝게. 카드(모드·레시피)와 목록 항목(도구·가이드)은 오버 시 테두리 밝게 + 2px 위로, 누르면 scale .98.
- 움직임: 히어로 답변 줄이 화면에 처음 들어올 때 한 줄씩(마지막 문장은 타이핑처럼, 총 1.4초), 탭 선택 표시가 미끄러져 이동(.26초) + 내용 180ms 페이드, 수치 띠 숫자가 0에서 700ms 동안 올라감, 히어로 밖 섹션은 처음 보일 때 8px 아래에서 떠오름. 모두 IntersectionObserver로 한 번만, 이징 cubic-bezier(.2,.8,.2,1). 숨김은 head 스크립트가 붙인 `html.motion`에서만 걸리므로 스크립트가 꺼지거나 reduce면 처음부터 다 보인다.
- 추가 마크업: 추천 근거 머리 아래 수치 띠(문구는 기존 "검증한 도구·레시피·가이드"), 모드 카드의 "Mode · 보완/신규" 라벨을 상태 배지로.
- 확인(8795, Chrome): 1440×900·375×812 모두 가로 스크롤 0, 12px 미만 0, 16px 미만 4종, 모든 탭·전체 보기 동작, axe(wcag2a/2aa/21aa) 위반 0. reduce 컨텍스트에서 motion 클래스 없음·숨은 요소 0(giscus iframe 제외). 콘솔 오류는 giscus의 github.com 프레임 차단(CSP) 1건뿐.

## 3차 타이포(2026-11-09)
- 히어로 제목 두 줄·두 톤: 1줄 "프로젝트를 먼저 읽고,"(#f4f4f2, "먼저 읽고"만 앰버·줄바꿈 안 함) / 2줄 회색 `--dim` #7d828b. 데스크톱 clamp(56px, 6.6vw, 96px)(1440에서 95px), 휴대폰 40~44px(375에서 42.75px), 680 굵기, 자간 -0.035em, 줄간격 1.04. 설명 19px(휴대폰 18px). 제목 그라데이션 글자는 없앰.
- 섹션 머리 3단으로 통일(#demo·#how·#kit·#faq·#guestbook): 고정폭 12px 라벨(앰버 점 + 회색, 개수는 demo.json·catalog.json에서 채움) → 두 톤 h2(.hi 밝게 + 나머지 #7d828b, 데스크톱 40~60px·1440에서 59px, 휴대폰 30~34px, 630) → 17px 회색 요약. 2단 머리 그리드는 없애고 세로로 쌓음. 마무리 제목도 두 톤.

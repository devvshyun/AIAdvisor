    자주 묻는 질문

    더 궁금한 점은 방명록이나 GitHub 이슈에 남겨 주세요.

    스킬이 마음대로 뭔가를 설치하나요?

    아니요. 추천 단계에서는 읽기만 합니다. "2번이랑 3번 진행해줘"처럼 고른 다음에 설치를 시작합니다.

    추천 근거는 최신인가요?

    카탈로그는 항목마다 확인한 날짜가 있고, 30일이 넘은 항목은 바뀌었을 수 있다고 표시합니다. "카탈로그 갱신해줘"라고 하면 그날 기준으로 다시 조사합니다.

    Windows에서도 되나요?

    됩니다. 현재 OS를 확인하고 명령을 PowerShell이나 Git Bash에 맞게 바꿔 보여 줍니다.
